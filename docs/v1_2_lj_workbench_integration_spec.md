# V1.2 LJ 工作台接入规格

状态：第一阶段已实现
日期：2026-09-02
开发分支：`codex/v1-2-lj-integration`

## 1. 本阶段目标

把 V1.1 已启用的项目模板和批号配置接入单水平（LJ法）工作台：

```text
全局基础资料
  → 项目模板
  → 已启用批号配置
  → LJ 项目与批号选择
  → 现有结果录入、建靶、Westgard、维护和月报
```

本阶段不迁移普通旧测试项目，不从旧项目管理页面创建新业务配置，不修改 `qc_logic.py` 的 LJ 统计与 Westgard 算法。即时法“确认转入 LJ”生成的批次属于现行业务链路，继续作为受控来源进入 LJ 工作台。

## 2. 上游准入条件

进入 LJ 工作台的配置必须同时满足：

- 项目模板已启用且未停用；
- 批号配置已启用且未停用；
- 批号项目已启用、未停用，`qc_method = lj`；
- 输入值类型、单位、检测方法和试剂来自批号项目快照；
- 只配置一个有效水平；
- 当前第一阶段只接入 `target_source = building` 的本批次建靶配置。

人工、厂家和复制待确认靶值仍保存在 V1.1 配置中，但为了不改变现有 LJ 计算核心，本阶段不把这些配置放入工作台选择器；页面会列出暂未接入原因。

## 3. 内部运行绑定

新增 `qc_workbench_bindings`：

| 字段 | 用途 |
|---|---|
| qc_method | LJ、Z-score 或即时法；本阶段使用 LJ |
| project_template_item_id | 上游模板项目 |
| lot_config_id | 上游批号配置 |
| lot_config_item_id | 上游批号项目配置，唯一 |
| runtime_project_id | 现有计算运行时项目 id |
| runtime_batch_id | 现有结果表使用的批次 id |
| binding_status | active 或 inactive |
| source_revision_no | 已同步的批号配置修订号 |

运行绑定只是内部适配层：新版配置仍是唯一管理来源；现有 `projects`、`batches` 只承担稳定算法与结果表所需的运行时身份。普通旧测试项目没有绑定，因此不会出现在新版 LJ 选择器。即时法转入批次通过明确的 `source_method = instant` 进入，不放开其他旧项目。

## 4. 同步规则

- 打开 LJ 页面时同步所有符合准入条件的配置；
- 同一模板项目、同一输入值类型的多个批号复用一个运行时项目；
- 每个批号项目配置对应一个稳定运行时批次；
- 重复同步不重复创建项目、批次或绑定；
- 上游仪器、试剂、质控品、批号、水平、建靶点数和 CV 要求同步到运行时批次；
- 上游配置停用、改回草稿或不再满足准入条件后，绑定标为 inactive，不删除结果；
- 再次启用时复用原绑定和历史结果。

## 5. LJ 页面行为

- “项目与批号”页签只提供新版配置选择和配置摘要；
- 不再显示旧的“新建项目”“新建批次”和编辑表单；
- 即时法已确认转入的 LJ 批次继续显示，并保留来源项目、来源批次和转入时间；
- 提供“打开项目/批次管理”和“打开基础资料”全局入口；
- 当前批次展示检验项目、配置名称、仪器、试剂、质控品、批号、水平、单位、检测方法、输入值类型、建靶点数和 CV 要求；
- 结果录入、图表、离群维护、导入导出和 LJ 月报继续使用原有实现。

## 6. 报告

LJ 月报新增：

- 单位；
- 检测方法；
- “新版配置：本批次建靶值”的靶值来源说明；
- 上游配置名称写入来源详情。

报告历史仍保存生成时摘要，不因后续字典修改覆盖旧报告记录。

## 7. 验收路径

1. 在空数据库中创建厂家、仪器、试剂、质控品、批号和单水平；
2. 创建含 LJ 项目的模板并启用；
3. 创建批号配置，选择 `building` 靶值来源并启用；
4. LJ 选择器只出现该新版项目，旧测试项目不出现；
5. 录入 5 个有效建靶点和第 1 个正式期结果；
6. 原 LJ 统计判定建靶完成，第 6 条进入正式期；
7. 月报带出单位、检测方法、仪器、试剂、质控品、批号和新版来源；
8. 重复同步不产生重复运行时项目、批次或结果。

## 8. 后续接入顺序

1. Z-score：复用运行绑定，按配置水平建立现有 Z-score 运行上下文；
2. 即时法：复用单水平配置并保留固定 20 个有效点规则；
3. 人工/厂家靶值：在不破坏现有建靶算法的前提下单独确定运行规则后接入；
4. 三种工作台全部稳定后，统一清理不再使用的旧管理入口代码。
