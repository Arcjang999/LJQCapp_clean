浓度编号是用户明确要求的独立字段，继续保留，并非两份手册完全同名的字段。“项目/批次设置已确认”沿用此前已确认的术语表，与“正式使用/停止使用”区分。“必须确认适用标准”是用户对本软件的要求；Q-expert 第 56 页说的是优先推荐行业标准，不能混为同一规定。

手册位置见 [参考资料索引](references/README.md)。本轮只参考术语和操作表达，不采用手册中的浮动统计、TEa 比例换算、联网、权限或删除数据规则。
