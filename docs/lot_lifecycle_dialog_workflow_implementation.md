## 已完成的交互

- **更换质控品批次**：先搜索、选择原批次并查看各水平批号，再打开弹窗。可按检验项目、按水平更换；原同批号配置也保留整批换用一个批号的方式。保存后直接选中新批次，进入参数和质量目标核对。
- **新旧批号比对**：批次列表、检验项目列表、实际批号和当前使用状态分别展示；准备新批、登记验证、调整使用状态、部分水平换批均使用弹窗。已经建立的普通新批可直接打开；待确认普通批次仍可追加尚未加入的检验项目。按各水平登记批号的配置使用统一逐水平换批入口。
- **均值和标准差管理**：列表选择检验项目的批次，查看当前参数和历史版本；确认或调整时打开弹窗。显示全部水平、实际批号、均值、标准差、设定 CV、来源、依据、确认人和生效时间。未来版本明确显示“尚未生效”，不会当作当前参数预填。停止使用、停用或设置已变更的历史批次仅供查询。
- 上述弹窗均由明确保存按钮提交。Enter 不保存；校验失败保留输入；取消时有修改则确认放弃，也可继续填写。打开已有批次前同样确认放弃当前草稿。切换换批方式保留已选材料；离开页面再返回保留搜索、项目筛选、所选批次和页签。

## 对原链路的修正

1. 同一检测项同时配置不同质控方法时，按项目配置项身份确定换批范围，避免只勾选其中一种方法却带入另一种。选项同时显示检验项目和质控方法。
2. 未更换水平按实际 `qc_level_id` 保留备注和参数；存在当前生效的确认版本时，优先引用该版本，记录来源版本。重排后仍按原材料身份找到原参数，不根据新位置猜测。新材料参数为空；所有复制值仍是待确认值。
3. 保存后提示新批次名称，避免部分水平换批时用头部原批号描述整个新批次。
4. 弹窗保存前重新核对配置、材料、参数、验证或使用状态；冲突和失败均整次回滚。例行页面同步更新时间不计入冲突依据，避免用户正常填写也被误报“已修改”。

质量目标确认、效期、最新适用验证、正式使用准入、参数生效时间、规则重新累计和旧结果保留均复用已有服务。没有新增算法、数据库迁移或真实库写入。
