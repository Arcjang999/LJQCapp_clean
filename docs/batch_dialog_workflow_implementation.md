## 操作方式

1. 从项目工作台点击“批次管理”，直接进入该项目的批次列表；点击“批次设置”则定位到所选批次。
2. 批次页按项目筛选，可搜索批次名称、批号或检验项目。选择一行查看详情；材料组合的列表显示各水平批号，不再把第一个批号当作整批材料。
3. 选择检验项目后，查看浓度水平、浓度编号、批号、效期、均值和标准差、质量目标。正常查看不显示编辑输入框。
4. “新增批次”打开弹窗。保存失败保留输入；取消有修改时提供继续编辑或放弃。保存后仍选中新批次。
5. “编辑水平设置”打开独立弹窗，一次保存水平选择、各水平参数和原有 CV 要求；参数始终按具体质控品记录对应，调换顺序不串值。
6. “质量目标”单独打开确认弹窗，沿用原有标准或实验室依据填写流程。确认成功后返回原批次；更换材料仍须重新确认适用性。最后沿用“校验并确认批次设置”。
7. 已启用或已用于检测的批次不能直接编辑，即使停用后恢复为待确认也不解除历史保护；当前生效均值/SD 读取参数版本。调整已有控制参数仍从“批号使用与追溯 → 均值和标准差管理”进入。
