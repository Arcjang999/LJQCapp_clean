## 1. 目标与不可拆开的交付

管理员能够更正误录、补录漏记结果、屏蔽或排除记录且不删除原始数据。更正或补录后，必须更新对应计算、受影响的后续判读、图表、汇总、导出和新报告。

更正/补录与联动重算是同一交付，不能先开放“只改数值”的页面，把重算留到另一期。普通账号限制由 [任务 4](task_04_accounts_and_lab_scope.md) 提供。原“历史检测实际批号更正”并入本任务；已完成的试剂使用事件更正不能代替本任务。

## 2. 依赖与已有基础

依赖主框架、实际账号权限和既有结果/参数/判读/报告版本关系。复用任务 1 的失控事件、任务 2/2B 的常规及临时记录、任务 3 的报告和现有生命周期服务，不重复开发管理弹窗框架。

实验室与账号范围按任务 4 最终确认方案执行。所有更正操作针对具体检测记录或完整 run，不能通过修改当前默认试剂批号来更正历史实际批号。

## 3. 功能范围

| 操作 | 必须形成的结果 |
|---|---|
| 误录更正 | 按授权修正已核实错误的字段，保留原记录与有效更正值；明确原因、实际操作者和更正时间 |
| 历史补录 | 分别保存实际检测时间和录入时间，确认当时的实际批号、水平及适用参数，检测重复并插入正确位置 |
| 历史批号更正 | 核对原/新批号、检测系统、材料水平及参数影响；跨序列变化同时处理原序列和目标序列，不能只换显示文字 |
| 屏蔽/排除及恢复 | 原始数据保留，明确排除范围及原因；如改变计算纳入范围则同步更新受影响统计和判读，恢复亦然 |
| 数据展示 | 表格和图表展示当前有效结果，追溯明细可查看原值、变更与原判读；不要求把全部日志铺到主图 |
| 失控与报告 | 保留原事件和报告依据，更新有效判读及受影响状态，新生成报告采用最新有效计算；支持生成更正版 |

本任务不提供隐匿真实异常、清除更正历史或向审计输出虚假完整记录的功能。真实失控后的重测作为新关联检测保存，不能用更正代替实际复测。

## 4. 计算联动要求

1. 按检测项、检测系统、实际批次、水平、检测时间及参数版本确定影响范围。只改一条记录时，也需检查后续连续规则；不能只刷新当前行。
2. 沿用现有算法重算有效点数、均值、SD、CV、相应 Z 分数及在控/失控判读。多水平法保持完整 run 和既定联合判定。
3. 建靶源数据变化时处理参数及下游依赖。厂家/人工固定参数与由样本计算的参数分开，不因补录一条数据就随意替换固定参数。
4. 历史补录按实际检测时间归位，不以录入时间追加到序列尾部；相同检测时间的次序和重复判定沿现有规则核查，规则不足时列明待定。
5. 临时记录沿任务 2B 确认的独立判读与统计归属重算，不混入常规 L-J 统计。
6. 数据、有效判读、统计缓存及前台展示保持一致。计算失败或未完成不能报告为更新成功，也不能显示新数值配旧结论而不说明状态。
7. 导出、单份新报告和批量新报告使用相同有效结果。原始数据、历史参数/判读和原报告版本保留，不静默覆盖。

具体事务或版本发布方式是技术实现选择；验收要求是结果一致、失败可恢复、重复操作不会新增重复有效记录。核心公式和质控规则不因本任务改变。

## 5. 验收场景

- 将一个误录值更正，核对均值/SD/CV、当前点及受影响后续连续规则、图表、汇总和新报告均更新。
- 在历史中间补录一点，核对实际时间排序、参数适用范围、重复检查及后续判读；重试不新增重复点。
- 更正建靶数据，按确认方案处理参数版本和下游结果；更正固定参数下的检测值不错误修改固定参数。
- 更正实际批号，原/目标序列归属与统计一致；多水平记录完整，未更正水平和历史来源可追溯。
- 临时更正/补录更新独立结果，常规统计仍符合任务 2B 隔离规则；原失控处理和复测关系可查。
- 排除和恢复后，数据表、纳入数、统计及报告口径一致；原始记录始终保留。
- 保存或计算失败时不出现已成功的半套状态；权限撤销、重复提交及陈旧窗口不能越权或覆盖他人更正。
- 页面、导出、单份及批量更正版报告结果一致，原报告可查；备份恢复后更正链、补录来源和有效版本一致。
