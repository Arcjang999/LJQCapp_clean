# 实验室自定 Ct 线方案

2026-11-06。用户在布局和说明确认后明确授权实施，本方案已在本地完成，验收及范围见[交付记录](deliveries/CT_ALERT_LINE_2026-11-06.md)。选项由项目输入值类型为Ct控制，检测后在原判读栏显示提醒。以下保留采用的设计。

## 入口与显示

放在质量要求页的“要求与文件依据”大区域顶部，先显示 **实验室自定 Ct 线** 复选框和问号，默认不勾选。复用新建项目、项目质量目标和新批次质量目标的共用表单。

勾选后，在复选框下方展开独立带边框的设置区，内含“Ct要求”下拉框、“Ct界值”数值框及各自问号。取消勾选时隐藏整个Ct设置区。原文件信息及“实验室实际要求”多行文字框保留在其下方，与Ct设置区分开。

界面层级如下，字段中的数值为已填写示例：

```text
要求与文件依据
  ☑ 实验室自定 Ct 线  ?
  ┌──────────────────────────────────────┐
  │ Ct要求 [ ≤ ▾ ]  ?   Ct界值 [ 38 ]  ?  │
  └──────────────────────────────────────┘

  使用的说明书或实验室文件名称
  [                                    ]
  设置日期或文件版本
  [                                    ]
  实验室实际要求
  [                                    ]
  [                                    ]
  说明此要求如何用于本次检测
  [                                    ]
```

Ct条件由独立控件保存，判读读取对应设置。原多行文字框继续存放实验室填写的具体要求；Ct功能说明由复选框及字段旁的问号提供。

显示条件为项目的 **输入值类型＝Ct**。其他输入值类型隐藏整个选项，选项内不提供修改输入值类型的入口。显隐不由“定性检测”选择决定。

项目原有输入值类型和检测条件校验继续执行。复制或导入时同样检查输入值类型，Ct设置只随Ct项目采用。

## 勾选后的内容

| 字段 | 建议 |
| --- | --- |
| Ct要求 | `>`、`≥`、`<`、`≤` 四选一，表示符合要求的条件 |
| Ct界值 | 填写有限数值，初始留空 |
| 要求摘要 | 随输入显示，例如 `Ct ≤ 38`；38为操作示例 |
| 使用依据 | 复用框内的文件名称、日期或版本、适用说明及确认人 |

首版每个检验项目配置一条提醒线。检测值不符合所填Ct要求时触发提醒。例如要求为 `Ct ≤ 38`，38符合，38.01触发提醒。若后续需要上下限，两项同时满足才符合要求。阈值和比较符须单独保存，文字说明用于记录依据。

## 界面说明与问号文案

以下为实施时统一采用的文案。数字只用于说明边界；新建时比较关系和界值均留待选择、填写。

| 位置 | 显示文案 | 问号说明 |
| --- | --- | --- |
| 勾选项 | 实验室自定 Ct 线 | 录入结果后核对所设Ct要求。不符合时显示黄色提醒；质控失控时显示红色。 |
| 比较关系 | Ct要求 | ≤、≥包含界值；<、>在等于界值时触发提醒。 |
| 数值输入 | Ct界值 | 按说明书或实验室文件确定，支持小数。 |
| 判读栏标题 | 判读 | 绿色为在控；黄色为质控警告或Ct提醒；红色为失控。具体原因见记录详情。 |

勾选项旁使用一个问号承载功能解释。勾选后，两个设置字段显示在独立带边框区域内，避免常驻段落重复问号内容。文件名称、版本、确认人沿用下方现有填写项；“实验室实际要求”保留实验室填写内容。

### 判读栏与记录详情

| 情况 | 判读栏主文案 | 颜色 |
| --- | --- | --- |
| 质控在控、Ct符合 | 在控 | 绿色 |
| 质控在控、Ct不符合 | Ct提醒 | 黄色 |
| 质控警告、Ct符合 | 警告 | 黄色 |
| 质控警告、Ct不符合 | 警告；Ct提醒 | 黄色 |
| 质控失控、Ct符合 | 失控 | 红色 |
| 质控失控、Ct不符合 | 失控；Ct提醒 | 红色 |
| 建靶中、Ct不符合 | 建靶中；Ct提醒 | 黄色提醒，保留建靶状态 |

记录详情使用“实测Ct”“Ct要求”“质控判读”“触发规则”四个名称。例如：`实测Ct：38.2｜Ct要求：≤38｜质控判读：在控`。仅在有命中规则时显示对应规则。

统一用“Ct提醒”，通过实测值和设定要求说明原因，避免把严格上限或下限都写成“超过上限”。例如要求 `Ct < 38` 时，实测38也触发提醒；要求 `Ct ≥ 30` 时，实测30符合。

### 操作帮助

> 输入值类型为Ct的项目，可在“要求与文件依据”勾选“实验室自定 Ct 线”，在展开的独立设置框中选择Ct要求并填写界值。检测后查看判读栏：Ct不符合时显示黄色提醒，质控失控时显示红色。记录详情列出实测Ct、设定要求和触发规则。

## 判读与展示

- 输入检测结果并完成判读后，在原有 **判读栏** 合并显示质控结论和Ct提醒。
- Westgard在控但不符合Ct要求时，判读栏显示 **黄色“Ct提醒”**，详情列出实测值和设定要求。原Westgard判读仍保存为在控。
- 颜色优先级：Westgard失控为红色；Westgard警告或Ct不符合为黄色；Westgard在控且Ct符合为绿色。Ct功能关闭时沿用原判读。
- 同时存在Westgard命中和Ct提醒时，判读栏列出两项原因，红色失控优先。
- 建靶中、待判读、SD为0等情况保留原状态，并可附加Ct提醒；Ct符合不能把这些状态改成在控。
- 底层分别保存Westgard判读和Ct提醒结果。Ct黄色提醒不计为Westgard命中或失控事件，原在控统计筛选保持。
- 网页L-J图、PNG及新生成PDF使用同一条标注为“实验室自定 Ct 线”的虚线。图表范围应覆盖已启用的线。
- 报告列出本批次采用的条件和提醒次数，失控次数继续按现有质控结论统计。
- 现有录入仍接收数值；无Ct、未检出等状态另按输入校验处理，不能补成0、38或40。

## 保存与生效

在 `quality_review_json` 中以独立 `ct_alert` 保存启用状态、合格条件比较符、阈值和配置版本，沿用现有依据、确认人和时间。

项目设置用于后续批次；新批次核对后保存采用值。当前批次质量要求在启用或绑定后冻结，首版沿用这一规则。每次结果保存当时采用的 Ct 条件和提醒结果，原结果与原报告继续使用原配置。

如果后续需要在用批次中途改线，另做按生效时间的参数版本；不能直接覆盖当前值后重算历史提醒。

## 验证范围

验证Ct输入显示、其他输入隐藏、关闭提醒、四种比较符的等值边界、非法数值、草稿重开、上游条件变化后的重新核对。覆盖Westgard在控且Ct不符合时黄色、原警告黄色、失控红色优先及建靶/待判读状态保留；检查Ct提醒不改变原质控统计。再验证复制、导入导出、换批、网页图/PNG/PDF一致，以及历史结果使用当时配置。

文案检查覆盖新建、项目编辑、新批次设置、保存预览、三种工作台的判读栏及记录详情、图例、报告、配置导出和应用内两种帮助视图。逐项核对字段名称、问号、就地错误、严格比较的等值说明及实际颜色；用户填写的要求与依据继续按原内容保存。
