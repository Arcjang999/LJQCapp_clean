## 范围与写法

逐页审读页面、弹窗、按钮、空白提示、错误提示和报告说明。必要的检验名称、均值、SD、CV、失控规则和医学标准名称保持；资料缺项指出具体内容，修改冲突给出重新打开或更新预览的操作，保存成功说明结果在哪里查看。

| 范围 | 检查内容 |
| --- | --- |
| 资料、设置、导航 | 单位资料清单、厂家、仪器、试剂、质控品及批号、换批、验证、均值与SD、保存位置、备份恢复和页面入口 |
| 项目与质量目标 | 单项和多项建项、质控品选择、标准引用、SD及CV、项目/批次确认、修改与取消 |
| 检测与记录 | LJ、多水平、即时法、单项/整组录入、建靶、记录维护、转入LJ、导入导出 |
| 失控与报告 | 原检测、原因措施、复测、效果确认、附件、期间报告、批量报告、报告历史与完整归档 |
| 服务提示 | 保存失败、重复提交、资料变化、停用、缺少原参数、文件损坏等通过页面显示的消息 |
| 帮助与配图 | 同一主文16节、关键操作加粗、3张真实界面标注图、按钮名称和编号说明同步 |
