# PDF 报告格式修复（2026-11-09，本地）

用户反馈导出报告的分节标题、表格和签署区域格式，要求使用测试数据验证。

## 修改

- `services/report_pdf_layout.py`：所有分节横线由标题顶部下移 0.012 页高改为 0.024 页高。原偏移约 10.1 pt，小于 12.3 pt 标题实际高度；旧位置可复现横线侵入字形约 3.04 pt。保留原分节总高度和正文字号，使标题、横线与正文各有间距。
- 摘要中的批号、浓度、各水平说明和来源说明直接使用原文，统一按实际字体与列宽换行，去掉先按字符数再按物理宽度的重复换行。能放入整行的英文单词、编号及括号保持完整，过长编号仍按列宽分行。
- `services/report_archive_service.py`：归档清单复用统一页脚，显示报告范围、清单名称和独立页码。沿用正文与处理附录分别分页的既定规则，未将已存处理报告改为整本连续页码。
- 新增标题间距、长中英字段、签署区、清单单页/多页及空清单检查。多水平月报原检查仍要求已清理的“尚无自动评价”旧提示，改为核对当前保存的质量来源名称与要求全文确实进入 PDF。
