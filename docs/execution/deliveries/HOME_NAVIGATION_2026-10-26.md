# 返回主页入口与返回按钮样式

用户反馈：希望顶部有按钮直接回到开始页面，返回按钮不要纯白。

顶部导航第一项新增蓝底白字的**返回主页**，在所有页面常显。点击后关闭全局页面并退出当前项目详情，直接显示首页“我的项目”列表；清除未消费的即时法转入LJ跳转，避免旧跳转覆盖返回主页。项目选择、搜索与筛选条件、各方法所选项目和批次、整组未保存输入、草稿编号及提交编号继续保留。原页面内的返回按钮仍按原目标返回，常用返回入口统一浅蓝底。

修改 `ui/common.py`、`ui/module_styles.py`，新增 `tests/home_navigation_smoke_test.py`，同步 `docs/OPERATION_GUIDE.md`。顶部栏在较窄窗口先显示软件名称，再显示导航，按钮可换行。
