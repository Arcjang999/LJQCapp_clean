# 即时法转入L-J后整组录入关联修复（2026-11-06）

用户反馈：即时法录入浓度并确认转入单水平L-J后，回到同项目整组录入，仍显示“即时法”，并提示原即时批次已转入、不能继续保存。

## 根因与修复

转入按原设计新建L-J目标批次，原即时法配置和绑定保留用于历史追溯。单项入口已经解析目标，但整组查询仍按原配置读取即时法；恢复同一批次草稿时还会保留旧的方法、运行批次和核对快照，两处共同导致报错。

- `services/daily_context_service.py` 复用已有严格转入归属校验，额外核对原绑定所属检验项；有效整组方法、批次、参数、结果和版本指向对应L-J目标。原配置、绑定和质量来源保持。目标错配、链条不完整、停用或试剂缺项继续阻止保存。
- `ui/daily_entry.py` 对尚未保存的即时法草稿识别真实转入，跟随L-J目标更新显示，保留检测值、备注、人员、检测时间和同水平选择，清除旧核对快照及导入预览，要求重新检查后保存。覆盖当前页重新显示、跨页返回、其他会话转入和缓存草稿恢复；已保存回执继续显示原保存快照。

试剂选项按同一检测系统查询，转入前后有效选项可以完整保留。截图中的试剂缺项不能仅凭截图认定由转入导致；本次保留实际试剂批号的原校验，没有自动造批号或放宽验证。
