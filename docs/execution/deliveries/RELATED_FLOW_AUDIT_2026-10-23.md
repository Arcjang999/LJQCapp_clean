## 检查结果

| 关联路径 | 确定问题与修复 |
| --- | --- |
| 缺基础资料→新建项目 | 原为空选择框或要求退出登记；新增“补充基础资料”，复用原编辑器在当前窗口补检验项目、仪器、试剂、方法学、单位及质控品产品，保存后返回并选择。新产品仍须另登记实际批号与各水平。 |
| 产品/仪器/试剂→厂家，检验项目→默认单位 | 原保存失败后要求取消去其他页面；现可进入子登记，类别按当前业务预选并校验，返回保留父名称、型号和备注。子资料只有明确保存才写入。 |
| 配套记录→项目前进或保存 | 原未保存子记录可被父保存清除；现阻止继续并提示先保存或取消。清空父试剂时子编辑器仍可继续或取消，保存按其原范围校验。 |
| 单项→多项及反向切换 | 原先处理顶部切换，再读取输入，会丢最后一次尚未单独更新的项目名/分组/备注；现先读取父输入再处理切换，双向验证。 |
| 空适用项目清单→整组添加 | 增加“自行选择检验项目”操作，沿用明确选择，不推断产品适用关系或质控方法。 |
| 换批列表→登记实际批号 | 原列表内联表单会受筛选/选择变化影响；现直接打开绑定所选原批次的单一设置窗口，登记时保留原批次与父草稿。 |
| 总览/项目工作台→批次设置 | 原仅传批次，混合项目需重新找检验项；现传具体检验项ID，目标管理页实际选中同一条。 |
| 整组录入无批次→设置→返回 | 原仅提示或进入未定位的全局页；现直达当前项目批次，清除过期导航意图，返回保留草稿及请求编号。 |
| 质量目标→批次，三方法无可用批次 | 清理失效选择、按所选检验项所属项目定位；无可用批次提供明确按钮。修正未选齐水平应先返回批次详情的提示。冻结无质量要求不再误称可继续录入。 |
| 单水平/多水平/即时法→试剂准备→返回 | 新增“登记或核对试剂批号”，按真实项目/批次/检验项/检测系统定位。多水平通过第二个表单提交动作带出最新输入，动作本身不保存检测；返回恢复检测人、时间、结果与选择，实际批号仍按原校验重新核对。 |
| 检测日期变化→实际试剂批号 | 原候选失效可能残留旧选择；现清空不可用ID，日期改回也不自动代选。 |
| 验证→使用安排，历史筛选→详情 | 验证成功说明下一步确认使用安排，失败不能用于使用。筛选隐藏历史行时清空选中，避免打开隐藏记录。 |
| 资料并发变化→导航 | 导航前校验项目/批次/检验项/系统归属；不匹配时不改导航和草稿。试剂准备读取失败也保留原输入与原返回状态。 |

后续登记不会补改已经保存的检测实际批号。原业务准入、效期、验证、适用关系、冻结与保存校验保持；不增加新的临床规则，不自动选择或伪造验证。
