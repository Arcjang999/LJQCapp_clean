# 质控品名录与管理弹窗（2026-09-28）

用户本轮要求：质控品管理首页就是名录，单选产品；新增、编辑、停用放在主页面，关联项目和批次由两个按钮分别打开弹窗管理。本记录优先于之前“产品名录／批号与关联项目”双页签的交付描述。

## 实现

- 独立质控品入口与基础资料复用同一名录；选择产品不跳转，不预选第一款；未选择时编辑、状态及两个管理按钮不可用，筛选移除当前产品时清空选择。
- 名录包含当前正式目录和手工新增产品，按稳定产品ID单选，保留厂商、产品编号、产品名称、浓度、浓度编号，补充状态；排除审计和测试目录不展示。已停用产品可筛选、查看并恢复。
- 主页面的新增／编辑／停用／恢复复用原资料与状态确认规则；保存后显示刚保存的产品，保留查询条件。
- “查看／管理关联项目”弹窗维护适用检验项目，并查看使用产品的项目。项目选择视图确认仅更新草稿，取消恢复原选择；填写核对人、参考资料并保存才持久化。选择视图返回保留刚输入的资料；关闭有未保存修改时确认放弃。
- “管理批次”弹窗只显示选中产品的实际批号和水平；新增、编辑、停用、恢复在同一弹窗流程内进行，保存或取消返回批次列表。搜索定位和停用恢复定位保留；切换产品不沿用上个产品的批号筛选。关联项目中的批次设置及换批继续复用既有入口。
- 使用说明和AGENTS已同步。无数据库结构变更，无算法修改，不提交或推送，不进入B4/B5，不打包。
