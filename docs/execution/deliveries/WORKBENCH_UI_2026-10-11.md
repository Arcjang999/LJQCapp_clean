# 三种方法工作区改造与导入导出整理

用户要求：先改造实际质控界面，并解决建靶期与正式期导入导出分开排列造成的混乱。

## 已交付行为

- LJ、多水平、即时法复用记录列表单选及操作弹窗。选中不自动编辑；详情、编辑、保留、禁用、恢复和异常处理根据记录与批次状态显示。筛选和排序按检测ID定位，隐藏所选记录会清空选择。
- 日常录入、质控图直接显示；已选项目和批次从工作台继承，资料放入折叠详情。LJ/多水平只保留当前批次与月度报告页签，即时法保留转入LJ入口。
- 维护需要填写原因。原始值与维护前后内容、时间和原因在同一事务内保存；失败全部回滚。取消可继续编辑或放弃；另一会话停用批次后保留关闭入口，保存仍按原对象验证。
- 正式期原始检测值及历史建靶记录保持原保护；多水平刚完成建靶即关闭编辑；即时法转入后原记录只读。多水平状态维护应用于整次检测的全部水平。
- LJ/多水平的导入导出改为两按钮和互斥弹窗。导入默认当前阶段，一次显示一套模板、上传、审查与预览；阶段切换清空旧文件和预览。复用CSV/单工作表Excel、数值尺度、完整水平、实际批号和阶段校验，确认时再次检查当前资料，整批写入。
- 数据导出默认全部阶段，每条标明阶段与实际试剂批号，也可只选建靶期/正式期及Excel/CSV。质控图可选当前视图或最长30天的正式期日期范围。月度PDF内容及统计逻辑未改，下载放在预览之前，预览折叠。
- 厂家参考值改为摘要与编辑弹窗，保存只更改参考资料，保留确认参数及原判读。资料发生变化或停用会阻止保存。
- 帮助中的操作说明已同步按钮及流程。
