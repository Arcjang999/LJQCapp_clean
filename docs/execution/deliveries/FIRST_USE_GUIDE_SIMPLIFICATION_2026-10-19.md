# 2026-10-19 首次引导用语与三步流程

用户反馈“准备资料”“准备单位资料”和“开始检测”含义不清，并明确指定“实验室信息 → 仪器试剂管理 → 新建项目”，要求首次引导入口高亮。本条覆盖同日此前四步引导的说明。

## 改动

- 引导只有三步：实验室信息、仪器试剂管理、新建项目。每步直接说明填哪些内容、点哪个现有按钮。取消独立“开始检测”步骤，最后一步提供真实建项入口和完成引导。
- 右上角“首次引导”、“继续首次引导”和当前步骤均为蓝底白字，在系统设置页面也保持蓝色。
- 第二步明确分列仪器、试剂和质控品：仪器填名称、厂家和型号；试剂填产品、批号和效期；质控品填产品、批号、效期和水平。
- 截图中原“准备单位资料”不再占据系统设置顶部。入口移到实验室信息表单下方的“从Excel批量登记资料（选用）”折叠区，按钮改为“下载填写表或导入Excel”；对话框同步说明是从Excel批量登记。逐项填写不依赖导入文件。
- 系统设置的填写区更名为“实验室信息”，帮助主文、章节索引和README同步三步顺序及实际按钮名称。
- “批号验证”保留在试剂管理，旁边增加“把实验室对这批试剂的检查结论和依据记在这里。”。它登记既有检查的结论、依据、确认人和完成时间，软件不替代实际检查；原有验证、换批和检测准入规则保持。
- 跳过、完成、已有项目抑制和进度恢复保持。已保存的原第四步 `start` 在读取时显示第三步“新建项目”，保留其跳过/完成状态；不清空进度，不新增表或手工迁移。
