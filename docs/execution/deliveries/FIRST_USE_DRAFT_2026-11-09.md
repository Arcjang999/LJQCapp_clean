# 新建项目的草稿保存与恢复（2026-11-09）

用户反馈首次设置页面中途无法保存，点击取消后只有继续编辑和放弃修改，重新进入需要重填。原先只有最终核对页的“确认保存并进入录入”会保存；关闭项目窗口即移除本次草稿。

## 修改

- 单项建项的检测设置、质量要求和最终核对页，以及新建多项项目页，增加“保存草稿并退出”，支持字段尚未填齐的状态。
- 新建项目的取消提示提供继续编辑、保存草稿并退出、放弃修改。放弃修改会删除当前已暂存草稿。
- 首页和首次引导有草稿时显示“继续新建项目”；重开软件后恢复填写位置、项目设置、各水平产品与批号、未确认的选品依据、质量文字、日期和浓度。首次引导不遮挡已保存草稿的继续入口。
- 最后核对页暂存后恢复到质量要求页，按当前资料重新核对。更换检测设置后清理旧质量确认，改回原设置也须重新确认。
- 项目正式保存成功后清除本次草稿；正式保存与草稿清除使用同一事务。
- 当前正在补充基础资料、登记质控品产品/批号或编辑配套关系时，继续要求先完成或取消该项登记。

## 保存接口

新增 `services/project_setup_draft_service.py`，在现有 `app_settings` 中使用独立键 `new_project_setup_draft`；无需数据库迁移或新依赖。保存不完整表单只写该键，不建立半套项目、批次或确认记录。

JSON保存日期、元组和数值输入，排除上传控件及按钮事件；PDF沿用现有质量草稿中的文件标识。创建草稿ID独立于控件token，切换单项/多项后继续更新同一份草稿；不同ID不覆盖或误删另一份草稿。存储失败保留原值和当前填写。
