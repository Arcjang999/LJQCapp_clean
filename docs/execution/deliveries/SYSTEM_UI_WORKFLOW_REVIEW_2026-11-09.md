新增修复的两个状态缺陷：

1. 均值和SD切换表单原先点击取消直接退出，姓名、依据和时间会丢失。现在有修改时先提供“继续编辑／放弃修改”，继续编辑保留输入。
2. 批次水平只选了新产品、尚未选原厂批号时，原先取消再继续会丢产品选择；初始无水平时也可能不算有修改。现在产品ID随现有草稿保存并参与修改判断；继续填写保留产品，批号未选时保存仍禁用。

## 标准原文与桌面外链

三个质量界面文件的目录、数值详情、定性/过程参考入口统一接入标准链接组件。保留已记录的国家卫健委全文PDF，8个WS/T版本增加精确对应的“国内标准信息”入口，展开复制栏目可复制地址。历史641—2018保持历史版本；自定来源不附加官方声明，标准目录、采用依据、限值和计算规则不改。

国内信息页在全国标准信息公共服务平台逐一核对了版本。实际Chrome点击 [WS/T 403—2024国内信息页](https://std.samr.gov.cn/hb/search/stdHBDetailed?id=19F7C41D0A4F4F14E06397BE0A0A9EF9)，新页显示对应标准号和《临床化学检验常用项目分析质量标准》，原填写页保留。全部映射及抓取结果在 `output/standard-links-2026-11-09/verification-sources.json`；本轮部分卫健委发布页返回412，641—2026 PDF请求超时，未把这些请求写成成功。

桌面源码原先没有接收 `target="_blank"` 的新窗口请求，符合 [Qt官方文档说明的未处理请求失败行为](https://doc.qt.io/qtforpython-6/PySide6/QtWebEngineCore/QWebEnginePage.html#PySide6.QtWebEngineCore.QWebEnginePage.newWindowRequested)。现统一处理同窗/新窗口HTTP(S)外链，由系统浏览器打开。相同本机来源的普通导航保留，报告popup通过 [download API](https://doc.qt.io/qtforpython-6/PySide6/QtWebEngineCore/QWebEnginePage.html#PySide6.QtWebEngineCore.QWebEnginePage.download)进入原下载处理，避免替换主填写页；其他外部协议不交给系统执行。
