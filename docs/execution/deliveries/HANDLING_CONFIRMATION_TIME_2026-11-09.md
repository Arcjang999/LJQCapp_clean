# 处理确认时间改为分钟控件（2026-11-09）

用户反馈手写确认时间因月份/日期未补零、冒号周围有空格而被拒绝，要求改成控件并精确到分钟。

## 修改

- 失控处理“人工确认”的确认时间改为日期时间选择控件，可分别选择日期、小时、分钟，步长60秒。字段变动只更新当前草稿，点击“确认完成”才调用保存。
- 时间与已核对选项均随当前处理草稿保留，支持返回提示中继续填写，以及保留草稿返回后重进。
- 新控件以 `YYYY-MM-DD HH:MM` 保存选择值；分钟输入与提交待确认时间、当前时间按分钟比较，解决提交后同一分钟的合法确认被秒级下界拦住的问题。
- 原有带秒或时区的服务调用继续使用原精度和校验，已保存的历史内容不改。确认人、明确勾选、状态转换、重复请求及版本追溯沿用原规则。
- 操作说明同步为选择日期和时分后勾选确认，再点击确认完成。

## 验证

两套隔离检查共25项通过：处理服务13项、处理界面12项；失败、跳过和越界为0。新增覆盖同分钟确认、前一分钟/未来一分钟拒绝、原秒级边界、时区、跨天、重复请求、时间与勾选状态往返保留。输入和失败操作均核对不产生新版本且全库不变，原检测记录不改。
