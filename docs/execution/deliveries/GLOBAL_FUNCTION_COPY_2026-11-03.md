## 改写方式与实际范围

| 区域 | 改写内容 |
|---|---|
| 项目入口与日常录入 | 整组入口改为“一次填写本项目各检验项目的全部水平质控结果”；检查、清空、保存分别解释检查项目、可恢复内容和保存范围。 |
| 文件与粘贴填写 | “带入结果草稿”改为“填入录入表”，明确文件内容更新上方录入表，整组结果由“确认保存整组”保存；预览解释会检查项目、水平、批号和检测值。 |
| 资料与产品 | 说明名录、批号、关联项目、导入预览及单位清单各自维护或检查的对象；锁定、冲突及缺项提示给出实际可操作位置。 |
| 项目、批次与质量 | 说明项目和首批建立、质量要求采用、验证与使用安排、换批及参数切换的实际结果；累计统计使用实际质控品、批号和水平的业务名称。 |
| 检测与维护 | 说明保存会更新质控图和判读，保留／禁用／恢复如何影响统计，多水平按整次检测处理，既有锁定范围保持。 |
| 失控处理 | “加入附件草稿”改为“加入本次处理”，说明附件随处理记录保存；保存草稿和提交效果确认分别说明保存内容和人工核对用途。 |
| 导航、引导、报告与设置 | 说明入口用途、新报告采用哪些信息、完整备份包含什么、恢复替换哪些资料；原报告读取、期间范围、恢复覆盖和重启条件保持。 |
| 帮助 | 同步16节操作说明中的新名称与功能解释，保持目录锚点、两种阅读方式和3张配图资源。 |

快捷建项还补齐了项目名称和单位两处既有必填字段的就地红框／短提示，复用 `required_field`。字段key、校验、前进按钮条件及保存逻辑保持；测试仍检查缺项时阻止前进、草稿保留及数据库无写入。
