# 桌面源码保护（2026-11-11，本地）

## 本轮范围

用户同意处理源码仓库公开和安装包明文源码的问题，随后明确先做源码保护，暂不实施测试授权。测试截止时间已指定为 **2026-11-30 23:59（Asia/Shanghai）**，本轮仅记录，不在现有程序启用到期限制。

原已发布0901两端程序归档各含174个应用 `.py` 文件，安装器与签名更新并未隐藏这些文件。本轮修改后续桌面构建方式，不改业务算法、在用数据库或现有公开下载文件。

## 实施

- `app.py` 保留薄入口，原导入、辅助函数及页面执行序列移至 `app_main.main()`。AST逐节点核对与原执行顺序相等，每次Streamlit重跑继续执行初始化和路由。
- 新增 `packaging/protected_runtime.py`：用固定构建依赖将172个业务模块编译为平台扩展，覆盖核心根模块、services、ui、pages、migrations和run_app。编译源及C/object中间文件留在私有构建工作目录；运行目录只保留编译模块、两个薄入口、四个空包标记和公开资源。
- Windows/Mac业务服务均优先从独立编译目录解析模块。由于编译模块不再暴露普通导入供打包器分析，构建前从源码AST收集依赖；Analysis检查拒绝业务模块退回Python字节码或遗漏本机扩展。
- 两端Qt启动器同样使用编译版本的release_info/storage_paths，阻止从启动器重复携带这些业务模块的字节码。
- `release_payload.assert_protected_payload()` 检查整个组装成品，包括外层启动器目录；明文业务源码、业务pycache、非预期入口内容和缺失扩展均导致构建失败。现有Windows/Mac构建和原生验收已接入该检查。
- 构建依赖独立保存在 `requirements-build.txt`，并纳入源码身份白名单及现有GitHub构建步骤。开发、网页版继续使用普通源码运行，安装用户无需安装构建工具。
- 为Cython兼容作三处等价表达式调整：两个换批窗口中的列表展开，以及质量目录的固定字段元组；时间边界、字段顺序及规则不变。

编译保护提高获取业务实现的门槛，不承诺客户端绝对无法逆向。后续加入授权模块时，客户端模块需纳入编译与源码身份清单，服务端配置和私钥不得进入桌面成品。

## 仓库访问与自动更新

只读核实仓库当前为公开状态。现有桌面客户端仅访问自有服务器，Actions检出和产物下载使用GitHub自动令牌，不依赖本仓库匿名raw。服务器今后的源码拉取需采用既有授权访问或受控Git bundle；当前业务运行不需改动。

`desktop-updates` 环境承担签名及每周清单续签。首次核对时，账号接口未提供套餐信息、浏览器未登录，未确认私有仓库是否可继续使用该环境。执行改私有被自动审批审核拒绝，理由是关键前置条件未确认，可能中断自动发布；随后用户明确选择先登录核对，仅在确认不影响自动更新后再改。该操作没有执行，未绕过拒绝，未移动密钥或放宽发布保护。现行清单有效期为北京时间2026-11-23 12:56，不能把当前运行正常等同于后续自动续签已验证。

在已登录的[个人账单页面](https://github.com/settings/billing)核实：账号当前是 **GitHub Free，0美元/月**；[个人套餐比较页](https://github.com/settings/billing/plans)显示 **GitHub Pro为4美元/月**，与公开价格页的Team套餐分开核对。没有进入付款提交、升级订阅或修改预算。

Free本身支持私有仓库；但[官方环境说明](https://docs.github.com/en/actions/reference/workflows-and-actions/deployments-and-environments)明确，Free的环境密钥仅供公开仓库使用，Pro等套餐才支持私有仓库的环境密钥及部署分支限制。当前现有发布使用该能力，因此不满足“保持现有自动发布不受影响”的条件，仓库保留公开状态。后续由用户选择升级Pro，或另行实施并验证免订阅发布方案；不能通过去掉环境、下放密钥或取消main限制直接绕过。

私有仓库的云端构建还需核对额度和预算：[当前官方额度](https://docs.github.com/en/billing/reference/product-usage-included)为Free每月12美元计算额度/500MB Actions成品存储、Pro每月18美元/1GB。Windows和Mac按各自费率消耗额度，不能将旧2000/3000分钟当作两平台各自的免费时长。超过额度的收费或停止行为取决于付款方式及硬预算设置；本轮没有更改任何收费设置。
