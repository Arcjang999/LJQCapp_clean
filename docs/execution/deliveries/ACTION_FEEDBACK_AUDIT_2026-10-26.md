# 填写与操作提示关联普查

用户反馈新建项目的质量要求页无法进入下一步，又看不到原因；部分提示需要返回上一页才能修改。随后要求把其他填写页面一并排查，并提供已登录的服务器后台。

## 原因与修复

截图场景为丙型肝炎病毒RNA、实时荧光PCR、Ct、研究用途、血清，确认人已填但底部确认项未勾选。原按钮按确认条件禁用，却没有直接说明缺少该操作。现在确认人和确认项就地标出必填，按钮上方按当前输入列具体待办；勾选后提示消失，原有下一步条件随之满足。没有要求用户通过更改真实检测用途或结果类型绕过校验。

普查从 `ui/`、`pages/`、入口中233处包含 `disabled=` 的候选位置开始（包含字段锁定、服务参数等，不能当作233个按钮），继续追踪填写控件、保存校验、草稿和实际返回入口。

| 流程 | 修复或核对结果 |
| --- | --- |
| 新建项目三步 | 项目名称、重名、基础资料、材料和产品确认复用原保存检查，提前在检测设置页检查；前一步失效给实际返回入口；预览可直返检测设置。 |
| 质量要求 | 条件、单位/方法不符、确认人、确认勾选、水平浓度/类别、自定要求、CV、官方查找或补充资料均指向实际控件和所在步骤；原来指向不存在“保存，稍后继续”的新建页提示已修正。 |
| 质量窗口返回 | 项目窗口指向“返回项目→编辑检验项目”；批次窗口说明创建时固定的单位、方法和输入类型需修改项目后新建批次采用，避免引向不能编辑这些内容的水平窗口。 |
| 质控品适用确认 | 缺产品、人或依据时逐项说明；修改人工确认内容后旧确认在本窗口失效，输入保留，重新点击确认后才继续。 |
| 多项项目/整组设置 | 缺来源、勾选或统一修改字段时说明具体选择框；登记资料/配套关系尚未完成时，说明先保存或取消哪一条。 |
| 批次与换批 | 区分未选项目、停用和设置未确认；错误指向水平、质量目标或产品批号/效期；只读时不再要求点不可用按钮。清空换批项目后重选的名称映射异常已修复。 |
| 基础资料填写 | 厂家类别、仪器型号/单位、试剂产品的既有必填与保存错误保留；质控品新增水平的名称、编号、货号在切换已有水平后可恢复最新输入。已引用产品和批号明确先保存/取消返回列表，再新增。 |
| 参数与参考值 | 只读均值/标准差不再提示点击不可用的确认按钮；厂家参考值保留具体只读原因，其他窗口未结束时说明先完成或取消。 |
| 验证与使用记录 | 无可用验证时说明在当前窗口应如何返回登记验证，再重新进入；试剂使用历史更正保留填写并提供同样的正确入口。 |
| 录入与文件 | 粘贴内容或文件变化后提示重新预览；未选项目、未上传、未检查或没有有效行时说明具体操作；非法导出日期不再误称没有检测记录。 |
| 报告与失控处理 | 批量报告缺方法/报告选择时解释原因；即时法转LJ条件直接展示；失控提交前先保存草稿由悬停说明改为当前页可见说明。 |
| 导入与备份 | 项目配置导入、单位资料审查、恢复和迁移缺少前置操作时，指向实际按钮；质量要求CSV确认随文件内容失效，不能沿用上一份文件的勾选。 |

原来已正确关联的操作保持：列表先选行再编辑、记录维护的只读原因、导入错误表、单份报告预览更新、批次实际材料和质量准入、明确的字段保存错误、取消确认和原子保存。没有通过放开禁用或跳过业务校验来消除提示。

## 草稿与范围

并发产生同名项目或上游资料失效时，质量页先保存本次事件提交的最新控件输入，按相同设置身份恢复，避免返回修改时丢失刚填写的确认人和说明；不同检测设置和不同窗口不共用这份输入。补充标准文件按原合同保留有效全文的SHA记录；无效新文件清除旧标识并持续提示重新上传。减少标准数量、关闭登记、更换检测设置或窗口后，不会恢复已经移除的文件记录；文件上传控件本身不直接恢复。

无数据库迁移、依赖升级或质控算法变化。所有自动检查使用隔离数据，不向运行库保存新检测或资料；本地浏览器使用最小临时夹具。实际Windows和指定200%缩放未在本轮实测。
