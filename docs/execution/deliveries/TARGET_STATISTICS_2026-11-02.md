## 操作与口径

- 新建项目时，每个检验项必选**月度统计**或**累计统计**，无默认项；多项项目可批量填写，再逐项核对。
- 月度统计取北京时间**上一个自然月**的有效记录。累计统计取**同项目检测系统、同实际质控品批号和水平，从开始到最新**的有效记录，包含当月，不因参数版本或保留水平换配置而重置。不同产品、批号、水平及检测系统不混合。
- 选择旁的问号悬浮说明两种范围。选择方式或产生新统计值均不启用参数，也不按月提醒。
- 从批次详情或“批号使用与追溯 → 均值和标准差管理”主动打开**切换均值和SD**，核对当前／本次均值和SD、有效点数、检测日数及记录区间，填写生效时间、切换依据和确认人，勾选后确认。
- 确认才新增参数版本；取消不改参数或统计方式。新版本用于生效后的结果，已有结果、原判读和已存报告保持。原人工／厂家参数入口继续使用。
- 即时法本身算法不变；经原流程转入 L-J 后，可使用同一统计切换入口。

纳入原有有效建靶记录和正式期在控记录。多水平正式期以整次在控为准，失控 run 的各水平均不纳入。禁用结果不参与；建靶可疑点沿用原有保留／禁用规则。SD按全部纳入点计算样本标准差，不平均各月SD。首次建靶仍须满足原有效点数要求；后续候选至少2个有效点且SD大于0。参数来源统计与原报告正式期统计分别标明。

## 关联、保存与防错

项目初始选择和批次当前方式独立保存。新批次继承项目选择，复制批次继承来源批次当前方式；批次切换不改项目默认选择、质量确认或已冻结配置。Excel新增可选列“均值和SD统计方式”，支持中文标签；未填写仍待选，非法内容拒绝整次保存。旧项目空值不回填，不妨碍已有项目继续使用。

候选冻结实际产品／批号／水平、检测系统、每条纳入记录及判读来源、范围、数量和统计值。确认时服务端重新计算并逐项核对；新结果、禁用或判读变化、参数／策略修订、篡改数值或归属均要求重新核对。参数版本与批次方式在同一事务保存，失败不留半条记录。生效时间不能早于纳入记录、当前批次末条结果或上一版参数。

即时法转入来源须核对双方归属及冻结快照，仅计算转入后的 L-J 记录一次，不伪造或改写实际绑定。日志、页面和新报告可追溯月度／累计来源、实际样本区间和点数。
