# 对照与质控要求按本地设置（2026-09-28）

用户明确：已明确适用的分析质量标准继续强制采用；“对照与质控要求”不能要求全部照用，应自动带入标准参考并允许按当地或本实验室要求修改。

本轮只将 `kind=process` 改为参考。首次补齐检测条件后，自动选择匹配的现行参考来源并填入可编辑正文；允许删减、清空、不选任何来源，提供“重新带入所选参考要求”。已修改或已保存的正文不会因普通页面刷新、重新打开而恢复默认值。定性要求、信号精密度及数值限值仍按既有适用规则核对，未明确适用的来源不能作为已选参考保存。

参考来源与本实验室实际正文分别保存在现有质量复核 JSON 的 `process_requirements` 内；候选标准原文保持不变，参考不标记为强制采用。项目、新批、复制草稿、日常录入准备、运行来源和月报快照沿用该字段。月报、失控处理报告和项目导出分别显示本地正文与参考来源；正文留空时不回填标准原文。

没有新增数据库表或迁移，没有修改质控计算或自动判读。只调整新配置的对照与质控要求；已有批次的历史来源仍按其保存记录展示。保留全部现有工作区和演示资料，不打包、不提交推送，不进入 B4/B5。
