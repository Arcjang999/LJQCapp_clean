# 质控品及基础资料管理入口纠偏

2026-09-28，按用户反馈回读“优化质控品管理系统”原讨论（任务 `01a0c2c7-054f-7a03-b3b2-7b3c00dabd5a`），补齐目录首次准备及实际管理入口。下列20项自动检查、最新代码实际浏览器操作及演示数据保留复核已通过。

## 原要求与此前遗漏

原讨论及[面聊确认记录](../../2026_09_21_iqc_meeting_requirements.md)、[合并需求](../../requirements_merged_2026_09_21.md)、[任务2A](../../task_02a_master_data_and_catalog.md)要求：质控品有独立管理入口，产品名录可直接查询，并与实际批号和关联项目衔接；厂家按业务分类维护，仪器复用现有实验室资料，试剂复用已有批号管理和换批操作。

此前B2的正式目录发布只在隔离测试库验收。本轮修正前，当前演示库和正常使用库的目录发布记录均为0；仓库内有目录文件不等于当前数据库已导入，也不等于实际页面可查询。此前关于“演示已具备目录”的笼统描述以本条纠正，不将历史测试结果改写为当时演示可用的证据。

## 本轮改动

| 入口或资料 | 当前行为与边界 |
|---|---|
| 应用启动与邦德盛名录 | 启动时准备已确认的内置目录。缺少正式来源时导入1054项主目录和252项排除审计；已有正式来源时直接复用，不用随附旧版本覆盖。当前演示库已确认具备1054/252；正常使用库的实际启动结果仍须按实际环境核对。 |
| 质控品管理 | 顶部独立入口，默认“产品名录”，可搜索、筛选并“管理所选产品的批号与项目”；“批号与关联项目”展示所选产品、实际批号及已有项目关系。基础资料的质控品页签复用同一名录和管理区，弹窗只显示一次。 |
| 新建项目 | “从产品名录选择”后使用所选产品的实际编号关系，不按显示名称另造产品。选择目录产品保留用户已选质控方法；未知方法仍由用户设置。 |
| 产品与实际批号 | 产品编号、产品名称、浓度、浓度编号四字段保留原文；浓度与浓度编号任一项有效即可。阴性、阳性、分型、基因型及位点不数值化；不补造浓度、实际批号、有效期、靶值或标准差。多水平产品不自动选择多水平法或覆盖原方法。 |
| 已有项目与换批 | 从所选产品的真实使用关系打开关联项目或批次设置，换批调用已有操作；不从产品名称猜覆盖项目，也不建立虚构项目关系。 |
| 厂家管理 | “资料与批次”下独立入口，按仪器、试剂、质控品三类查看和维护；同一厂家可以兼属多类。 |
| 仪器管理 | 复用“系统设置”中的本实验室资料，查看已登记仪器及该仪器关联项目；不引入多实验室、多租户或账号权限。 |
| 试剂管理 | “试剂资料”与“批号与换批”衔接；选择试剂后管理其真实批号，复用已有登记、验证记录和换批操作，不新增比对算法。 |
