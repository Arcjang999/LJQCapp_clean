# 桌面验证码授权（2026-11-12，本地）

用户确认本轮按设备台数限制验证码，并统一设置使用期限。客户端、独立授权服务、首次启动界面，以及业务数据库读写和提交处的授权检查已完成本地实现；尚未部署或发布给客户。

## 已确认规则

- 每个验证码默认最多绑定10台电脑。
- 默认截止时间为 `2026-11-30T23:59:00+08:00`，即北京时间2026年11月30日23:59整。
- 用户安装后第一次打开软件时输入验证码并联网激活。Setup安装过程中不输入验证码，也不占用设备席位。
- 首次激活必须联网。之后自上一次成功验证起最多允许24小时断网使用，且不得超过验证码的总截止时间；断网或重启软件不会重新开始计时。
- 同设备身份的重试、正常更新，以及保留授权身份的程序重装不增加席位。设备身份丢失时，由管理员核对并解绑后恢复。
- 验证码停用、设备解绑等变更在下次联网验证时生效；已签发的离线租约最多继续至原租约到期，最长24小时且不越过总期限，不能承诺即时踢下线。

## 本地实现

客户端将设备身份和授权状态独立保存，不放入业务数据库，也不随业务备份迁移到另一台电脑。设备用独立Ed25519密钥响应服务器的90秒一次性挑战；证明绑定当前操作、设备公钥、机器摘要和完整请求摘要，避免复用其他请求的证明。

服务端使用独立SQLite授权库，以事务原子完成设备席位计数和激活。相同设备请求保持幂等，第11台被拒绝；解绑和启停使用许可或设备代次处理。服务器签发用途分离的Ed25519授权凭证，租约期限同时受24小时和总截止时间约束。停用、满额、解绑、过期以及签名错误均按明确拒绝处理，不能伪装成网络故障使用离线宽限。

授权签发私钥不进入源码、Git、安装包、更新包或客户端资源。公开信任资源的SHA-256摘要固定在编译模块中，防止替换公开配置后自行指定签发公钥。首次启动界面与业务数据库读写、提交边界共用许可检查，不能只通过跳过激活页面进入业务操作。

首阶段验证码生成、列表、设备查看、启停、延期和解绑通过服务器本机CLI管理；随后按用户要求已补好独立登录的管理页面及IP记录，见[管理页面交付](LICENSE_ADMIN_2026-11-12.md)。管理入口不进入现有展示网页，尚未部署正式网址。配置、命令、部署方式和期限语义见[服务器操作说明](../../../licensing_server/OPERATIONS.md)。

本轮新增模块继续沿用既有源码保护。178个模块已实际编译为本机扩展；未在本机运行Qt、安装器或冻结版应用，不能据此声称Windows/Mac实包验收或发布完成。
