# 实验室自定 Ct 线交付

2026-11-06，本地完成。用户确认在“要求与文件依据”放独立开关及设置框，并授权同步说明、问号、判读颜色、图表、报告和上下游关联。采用设计见[方案](../CT_ALERT_LINE_PLAN_2026-11-06.md)。

## 已实现行为

- 仅项目输入值类型为Ct时显示“实验室自定 Ct 线”，默认关闭；勾选后展开独立边框，设置Ct要求和Ct界值。“实验室实际要求”保留为独立文字框。
- 比较符表示符合要求的条件，支持`<`、`≤`、`>`、`≥`。例如Ct≤38时，38符合，38.2提醒。界值初始空白，确认前检查缺项和有限数值。
- L-J、多水平与即时法工作台、记录详情、整组保存回执和今日总览显示同一Ct要求及原因。在控且Ct不符合显示黄色“Ct提醒”；原失控与Ct同时触发显示红色“失控；Ct提醒”。建靶、待判读状态保留，即时法疑似离群沿用黄色。
- Ct要求和提醒独立保存，原质控状态、规则命中、在控/警告/失控统计及失控事件口径保持。多水平任一水平触发时整次显示提醒，整次失控时各水平图仍以红色优先。
- 网页、PNG、PDF以虚线标出Ct界值和比较符，黄色点标出Ct提醒；图表范围包含启用的界线。历史采用条件不同时按记录分段。
- 新生成报告列出采用的Ct要求、提醒次数及明细；多水平同次多个水平触发计一次，质控统计继续按原结论。原报告文件保持。

## 关联与历史

`quality_review_json`增加可选`ct_alert`，包含版本、比较符和界值，沿用文件依据、确认人和确认指纹。草稿可以保存未完成设置；修改Ct设置会清除旧确认和快捷预览，其他输入保留。

新建、编辑、保存预览、项目复制及Excel配置导入导出接入同一设置。旧配置文件缺少Ct列时保留已有设置，显式关闭时清除当前项目设置；导入内容进入待核对状态。非Ct项目不能采用启用的Ct配置。

批次及结果读取当时冻结的来源，每次判读保存Ct采用条件和提醒结果。项目后续修改只供后续批次采用，旧批次、原结果及原报告保留原条件。即时法转L-J沿用来源和Ct要求。
