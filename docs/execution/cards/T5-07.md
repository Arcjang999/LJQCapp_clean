## 1. 目标与用户可见结果

源建靶结果变动时连同参数和后续计算处理；人工/厂家固定参数不随意重算。

## 2. 必读文件与复用入口

本文函数以拆分日代码定位；上游后续新增接口以已验收交付合同为准。拟新增位置不表示文件已经存在。

## 3. 逐步实施

1. 读取每个受影响参数的来源类型、来源结果列表、适用时段和确认状态，分清源建靶统计与人工/厂家固定参数。
2. 对由数据建立的参数按现有公式算候选新版本；按T5-01已确认方式要求必要的人工确认、记录原因并确定适用下游。未确认不得把候选替换为有效。
3. 保持历史参数版本和旧判读引用；当前有效计算在维护完成后必须采用本次确定的有效参数版本，不以留历史为由继续读旧值。
4. 固定参数下的结果更正只更新数据统计和相关判读，不擅自替换固定均值/SD；如实际输入的参数本身误录，按已明确的参数更正路径处理，不混同源数据变动。
5. 按依赖顺序重算各阶段及后续点，校验不存在候选数据配旧参数的新有效结论。缺来源链或不支持分支明示受阻，不猜填。
6. 把参数变更加入同一次发布计划；中途失败保留全部原有效状态。

## 4. 本卡不做与禁止

- 不新增暂定/常用参数、长期加权CV算法。
- 不静默撤销人工确认或将厂家参数变成样本统计。
