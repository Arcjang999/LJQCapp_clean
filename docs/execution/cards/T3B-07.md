## 3. 逐步实施、数据关系与失败行为

1. 准备两套有效方案及正常、低浓度、零分母、阈值/分段边界、样本量不足数据。
2. 分别从手工和专用模板完成预览、问题修正、保存、计算、人工结论及验证关联。
3. 测试重复编号、缺侧、非数值、单位/项目不一致及 Ct/log/定性不适用拒绝。
4. 修改已确认配对或标准，核对新版本与旧报告、验证链，并模拟失败与重复提交。
5. 生成所有代表性 PDF 逐页查看，再验证附件备份恢复、历史模糊检索及存储迁移。
6. 核对原日常数据和默认批号不被修改，整理已通过范围及尚未覆盖项后交给 T3C。

数据契约与状态：

- 每个自动评价都能追到完整方案，数值和接受条件可从原配对复算。
- 零分母与方案不完整不属于自动通过；统计完成与人工验证/换批相互区分。
- 本阶段不证明 Ct/log、定性、半定量或通用性能验证已实现。

## 5. Given–When–Then 验收

1. Given 两套完整方案及有效配对；When 走完全流程；Then 各自按其条件评价且能从原配对复算。

2. Given 零分母、低浓度及边界值；When 页面和 PDF 核对；Then 处理严格符合方案，没有无穷/假通过。

3. Given 配对修订或导出失败；When 重试及查历史；Then 原版保留，新版确认清楚且不重复造历史。

4. Given 比较确认并恢复备份；When 查看日常工作台；Then 默认批号和原 QC 结果没有因比较而被改写。
