执行前阅读 [统一执行规则](../EXECUTION_RULES.md)。本卡是待执行范围，不表示功能已经实现。

## 1. 目标及用户可见结果

- 已确认：可旧批正式/新批平行累积 20 个点后人工确认切换，也可直接结束旧批、重新累积新批。
- 待确认：各检测项/水平有效点计数、整组是否一起切换、直接换批未建靶期间判读及跨仪器范围。

## 2. 必读实际文件与复用函数

- `docs/task_03_comparisons_and_monthly_reports.md` §2 与合并稿 §6：20 点不等于 20 天或独立分析批。
- `services/lot_lifecycle_service.py::change_qc_lot / set_qc_usage_state / create_level_combination`：已有生命周期。
- `qc_logic.py::calculate_qc_results`、`zscore_logic.py::get_effective_building_run_count / should_enable_formal_rules`：既有计数与准入。
- `services/qc_replacement_edit_service.py::save_qc_replacement`：已实现各水平换批和旧参数引用。
- 所有业务搜索复用 `services/search_service.py::fuzzy_match / filter_frame`；选中后以稳定身份精确关联。

## 3. 逐步实施、数据关系与失败行为

1. 记录两种路径的明确行为、原结果保护和同产品首轮范围；区分状态切换与专门比对报告。
2. 列出多检测项各 19/20 点、三水平部分禁用、同日多次检测等计数示例，请业务确认有效点定义。
3. 分别讨论单项与整组切换、部分水平替换及跨仪器范围；保留水平真实批号，不自行加全库互斥。
4. 就直接换批无正式参数期间列出“能记录什么、能判读什么、界面如何表达”待答问题，不给默认临床算法。
5. 明确专门比较的纳入期、排除规则、最低数据条件和通过依据由实验室方案给出；均值接近不是万能标准。
6. 为每个答案记录范围及证据；比对对象、来源查询可先准备，未答计数/判读/切换分支不能上线。

数据契约与状态：

- 业务确认与实现建议分开记录；状态名、服务拆分可由实现提出，临床判定条件不能代定。
- 平行 20 点是指定新批路径要求，不修改所有 LJ 建靶配置或即时法固定规则。
- 直接路径不要求补造平行数据或平行报告；仍受现有批次、来源和适用要求检查。

## 4. 本卡不做与禁止事项

- 不把厂商参数复制当作人工确认完成；不把结果数称为独立分析批数。
- 不因一个切换规则未答阻塞无依赖的数据/查询准备，也不因此批准未定算法。
- 不修改既有质控公式、规则阈值或 Z-score 整次检测判定粒度；任务 0 的适用性继续精确判断。
- 界面不得显示编程语言、代码、开发说明、内部字段或错误堆栈；使用实验室业务用语。

## 5. Given–When–Then 验收

1. Given 同日录入 20 次；When 记录计数合同；Then 明确是结果点，不能自动写成 20 天或 20 个独立分析批。

2. Given 一个检测项 20 点、另一个 19 点；When 整组切换尚未确认；Then 保留待定，不自行整体放行或阻止所有资料准备。

3. Given 选择直接换批；When 核对交付清单；Then 不要求平行报告，但未建靶判读规则仍单独待确认。

4. Given 三水平仅换第二水平；When 审阅方案；Then 保留各水平实际来源，不宣布所有水平共用新批号。
