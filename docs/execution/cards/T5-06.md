## 3. 逐步实施

1. 分别接入即时法适配器和临时记录适配器，不用同一个“临时”标记混合业务含义。
2. 即时法候选按原有效点规则计算；覆盖2→3、19→20及排除后回落的边界，参数确认/转LJ仍是既有人工动作，不自动再次转入。
3. 已转LJ的来源数据被更正时，通过来源关联识别LJ依赖，按T5-01确认方案处理；不得只更新即时表而让已转入有效数据脱节，原转入历史保留。
4. 临时更正、补录与恢复使用T2B确认的序列窗口和参数合同；临时仍不纳入常规LJ统计，显示开关不进入计算输入。
5. 把两类输出都绑定候选版本；缺适用参数时沿业务合同返回明确状态，不自动选择最新参数。
6. 比较更正前后常规LJ统计，验证仅临时变化不会改变被隔离的常规纳入数/均值/SD/CV；即时法与原正常重放一致。

## 4. 本卡不做与禁止

- 不修改即时法3/20点规则，不在此决定临时跨点方案。
- 不自动切换批次/参数或重复转LJ。

以下数字和数据均为隔离工程样例，不代表临床接受阈值。
