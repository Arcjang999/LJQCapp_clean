- 原需求锚点：[原任务 3A](../../task_03_comparisons_and_monthly_reports.md#2-3a质控品新旧批号比对)；[合并需求](../../requirements_merged_2026_09_21.md) §4.5、§6。

- 证明 3A 同时覆盖两种实际换批路径，而不是只多了一张比对报告。
- 所有比较统计可复算、所有切换可追溯，新旧批历史结果保留。

## 2. 必读实际文件与复用函数

- `docs/task_03_comparisons_and_monthly_reports.md` §2：原验收范围。

## 3. 逐步实施、数据关系与失败行为

1. 准备普通 LJ、2/3 水平及部分水平组合，覆盖有效点不足、禁用/失控、跨参数版本和不同浓度。
2. 验证选批/选期、比较统计、方案、确认、专门 PDF 与验证关联完整链。
3. 分别执行平行 19→20 点人工切换及直接换批，无平行报告的直接路径必须独立通过。
4. 验证部分水平保留参数引用、完整组合确认及实际批号显示；检查指定范围外对象不受影响。
5. 注入保存/切换/报告失败及重复提交，检查回滚、可重试和历史版本不被覆盖。
6. 记录每个原验收项结果及未完成环境；阶段通过后向 T3B/T3C 交接比较与来源接口。

数据契约与状态：

- 没有全部决策答案的分支不得被阶段通过掩盖；只通过报告生成不算 3A 完成。
- 新旧批结果身份、原判读、参数版本及实际材料快照均在验收前后核对。
- 后续 T5 合法更正保留独立接口；本阶段换批本身不回写历史值或结论。

## 4. 本卡不做与禁止事项

- 不修改算法或下降数据门槛来让换批案例过关；不使用真实库做迁移演练。
- 不宣称完成跨产品、长期加权 CV 或全部独立分析批设计。
- 不修改既有质控公式、规则阈值或 Z-score 整次检测判定粒度；任务 0 的适用性继续精确判断。
- 界面不得显示编程语言、代码、开发说明、内部字段或错误堆栈；使用实验室业务用语。

## 5. Given–When–Then 验收

1. Given 平行新批条件满足；When 人工切换；Then 新数据连续保留且旧批指定范围停止使用。

2. Given 直接换批且没有平行报告；When 完成已批准流程；Then 可使用其独立新批累积/判读路径。

3. Given 3 水平部分换批和跨参数版本；When 查看页面及报告；Then 各水平来源与分段统计一致。

4. Given 切换或 PDF 中途失败；When 再试；Then 原数据和历史保留，无半切换或无提示重复报告。

## 6. 证据与完成条件

- 需求逐项矩阵、受影响回归、两路径浏览器记录和逐页 PDF 证据。
- 计数/参数/验证边界、事务失败和保护对象前后对照；明确依赖已解决或保留阻断。
- 证据逐条对应本卡验收编号，记录未执行项和失败原因；未通过不得勾选完成。
- 执行实现或验收时仅使用独立库/明确副本，记录版本和保护范围；此次编写卡片不运行应用或数据库操作。
