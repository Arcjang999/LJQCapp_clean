## 3. 逐步实施

1. 沿现有调用链核对run次序、规则模板、水平排列、参数版本及部分水平换批来源；适配输入但不重写算法。
2. 任何一水平误录更正都构造完整候选run重新计算联合结论；后续run按原连续判读规则重算，不将其他水平结论直接复制成最终结果。
3. 保留各水平实际批号、参数版本、Z分数和规则证据；2水平/3水平不能互相降级补齐。
4. 历史补录必须提交完整既定组合；时间或材料变更交给影响计划同时处理原/目标序列，缺参数不得默认套今天参数。
5. 输出与T5-04相同的候选计算版本合同，同时保存run级和水平级证据。
6. 用按最终有效顺序正常录入的2水平、3水平隔离对照验证逐次联合结论、统计和图形输入；检查未更正水平的原始来源仍可追溯。

## 4. 本卡不做与禁止

- 不把水平分别保存为独立run，不只更新一水平Z分数。
- 不改变联合判定或部分水平换批规则。
