# T2A-04｜建立产品目录来源版本与正式内容边界

- 原任务：任务 2A
- 状态：未开始

- 前置卡：T2A-03
- 本卡交付：可核查的产品目录导入与版本记录
- 原需求锚点：[任务 2A](../../task_02a_master_data_and_catalog.md) §2邦德盛产品目录、§3、§5；[面聊确认](../../2026_09_21_iqc_meeting_requirements.md) §2

遵循 [统一执行规则](../EXECUTION_RULES.md)；本卡未授权超出原任务的新功能。

## 1. 目标及用户可见结果

- 产品的货号、水平规格和覆盖项能追溯到具体资料与版本。
- 没有正式邦德盛资料时，系统能力仍可验收，但不出现伪造的正式内置产品。

## 2. 必读实际文件与复用函数

- `services/master_data_service.py`：`list_sources`、`create_qc_material`、`list_qc_materials`。
- `migrations/v1_1_master_data.py`：md_sources/md_source_records；`migrations/material_workflow.py`：md_qc_material_specs。
- `services/material_workflow_service.py`：`create_material_spec`；`services/material_catalog_service.py`：产品引用与版本锁。
- 拟新增`services/product_directory_service.py`及必要增量迁移；目录数据包格式在本卡合同中定义。

## 3. 逐步实施

1. 先清点用户提供/官方核实资料，记录发布者、文件名或链接、版本、取得日期、校验值与核查人；不主动扩展国家标准目录。
2. 定义目录产品稳定外部键、厂家ID、货号、名称、基质、物理形态、规格水平、覆盖检测项及逐字段来源。
3. 把资料未说明与明确不适用区分；未核实货号/规格/覆盖项留空或待核对，不以示例值补齐。
4. 实现只读导入预览：新增、修改、冲突、缺失字段和行号；产品身份按来源键或经核对的厂家+货号确认。
5. 正式目录发布要求来源可核查、产品身份唯一；人工本地产品独立保留，不被官方包按近似名称覆盖。
6. 同一来源版本与文件校验值重复导入返回既有结果；不同内容冒用同版本时报告冲突，不能静默覆盖。
7. 导入保存以一个事务写来源、产品和规格；发生任一字段冲突则本次发布不产生半套目录。
8. 更新目录只影响将来候选；已实例化批号、厂家参考值、结果上下文及报告快照不回写。
9. 正式资料缺失时用“隔离测试资料”包验证机制，形成待补资料清单；取消预览不写库，失败保留预览输入。

## 4. 不做与禁止

- 不把邦德盛测试样品、未经核实网页或名称代码字典当正式产品目录。
- 不从产品目录自动生成实际采购批号、效期或厂家靶值。
- 不因正式资料缺失阻断厂家、手工关联、panel及日常录入能力验收。

## 5. Given–When–Then 验收

1. 场景 1
   - Given：有可核实来源与两个唯一货号
   - When：预览后发布目录
   - Then：来源版本、产品和规格可追溯，产品本身没有虚构采购批号。
2. 场景 2
   - Given：同来源版本同文件已成功导入
   - When：再次导入
   - Then：返回原发布结果，不新增产品或来源记录。
3. 场景 3
   - Given：同货号的规格信息冲突或缺来源
   - When：提交发布
   - Then：冲突准确到行和字段，本次目录不半发布。
4. 场景 4
   - Given：只有隔离测试包没有正式目录资料
   - When：完成功能测试并打开正式候选
   - Then：测试包不进入正式内置候选，内容缺口独立报告。

## 6. 证据与完成条件
