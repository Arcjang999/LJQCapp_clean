## 1. 目标及用户可见结果

- 按项目、仪器、批号、日期或结论找到比对及其报告版本，能打开原配对。
- 重启、备份恢复和存储位置迁移后，比对依据、附件和报告仍可查看。

## 2. 必读实际文件与复用函数

- `services/report_service.py::filter_report_history_records / get_report_history_record`：历史筛选。
- `pages/report_history_page.py::render_report_history_page`、`ui/reagent_lifecycle_workspace.py`：现有入口衔接。
- `services/storage_service.py::create_database_backup / restore_database_from_backup_file / migrate_database_to_directory`：存储流程。
- 任务 1 附件实现及 T3B-02/05 版本关系；拟新增比较列表查询和恢复完整性检查。
- 所有业务搜索复用 `services/search_service.py::fuzzy_match / filter_frame`；选中后以稳定身份精确关联。

## 3. 逐步实施、数据关系与失败行为

1. 在原试剂比对/报告入口提供历史查询，条件采用业务名称和模糊查找，打开时精确定位记录。
2. 详情展示数据、方案、结论、验证、报告与修订链，已停用产品仍显示历史快照。
3. 复用附件上传下载和引用机制，记录文档用途；附件丢失不等于比较记录不存在。
4. 扩展或确认备份包完整包含本阶段新表、附件和报告文件，恢复检查所有引用关系。
5. 恢复到隔离目标后打开每个报告/附件，若缺件明确指出项目和文件，可重试恢复，不能显示完整成功。
6. 核对数据库位置迁移后相对文件关系有效；只沿用设置页已有选择目录与重启流程。

数据契约与状态：

- 检索用近似匹配，记录归属、验证及版本引用必须精确，不能串到同名不同项目。
- 已确认历史是只读查看；创建修订经过 T3B-04/05，不在查询页静默改配对值。
- 恢复失败保留原存储与可重试信息，技术堆栈仅进入日志。

## 5. Given–When–Then 验收

1. Given 批号包含相近字符；When 模糊搜索并打开其中一条；Then 能找到候选且精确进入正确比较版本。

2. Given 旧产品已停用；When 查看其比对历史；Then 原名称、两批和确认报告仍可见，不当作新可选产品。

3. Given 完整备份；When 在隔离目录恢复；Then 配对、方案、修订、验证、PDF及附件关系均可打开。

4. Given 备份缺少一个附件；When 恢复核验；Then 指明缺件且不称全部成功，其余有效资料可查询。

## 6. 证据与完成条件

- 模糊搜索、停用历史、修订链和恢复后打开资料的浏览器证据。
- 完整/缺件备份及存储迁移的关系检查；验证原日常数据与试剂使用记录未变。
- 证据逐条对应本卡验收编号，记录未执行项和失败原因；未通过不得勾选完成。
