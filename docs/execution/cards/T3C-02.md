# T3C-02｜统一单份月报生成与数据版本

- 原任务：任务 3C：批量月报与汇总
- 状态：未开始
- 类型：实现
- 前置卡：T3C-01；现有单份报告与任务 1 处理摘要已验收；临时内容按 T2B 已确认口径分支接入
- 本卡交付：批量与逐份生成共用的数据包、统计、来源及历史保存适配。
- 原需求锚点：[原任务 3C](../../task_03_comparisons_and_monthly_reports.md#4-3c批量月报与汇总)；[合并需求](../../requirements_merged_2026_09_21.md) §4.5—4.6。

执行前阅读 [统一执行规则](../EXECUTION_RULES.md)。本卡是待执行范围，不表示功能已经实现。

## 1. 目标及用户可见结果

- 同一批次同一月份逐份或批量生成，统计、采用质量要求、批号和参数追溯一致。
- 每份报告可识别其使用的数据及参数版本，为后续合法更正后的报告关系保留接口。

## 2. 必读实际文件与复用函数

- `services/report_service.py::build_lj_monthly_report_package / build_zscore_monthly_report_package`：真实单份生成器。
- `services/report_service.py::build_lj_monthly_report_pdf / build_zscore_monthly_report_pdf / save_lj_monthly_report_snapshot / save_zscore_monthly_report_snapshot`：输出与历史。
- `services/lot_lifecycle_service.py::report_lot_trace`、`services/quality_target_service.py::batch_quality_summary`：按版本追溯和适用评价。
- 任务 1 事件摘要、T2B 记录用途查询；拟新增薄适配层和可追溯版本引用，不另写一套月报统计。
- 所有业务搜索复用 `services/search_service.py::fuzzy_match / filter_frame`；选中后以稳定身份精确关联。

## 3. 逐步实施、数据关系与失败行为

1. 定义单份调用合同，将方法、批次、月份及选定有效数据版本传给共同生成路径。
2. 盘点生成器现有副作用和历史保存时点，使单份/批量使用同样有效输入、参数分段和统计口径。
3. 读取任务 1 未完成处理及临时归属的已验收接口；临时总数未定时只接确定的独立详情，不自创分母。
4. 捕获数据、参数、质量要求和处理摘要版本；生成中版本变化时重核该项，避免一份 PDF 混用两次数据。
5. PDF 内容准备成功后才进入该份历史保存；单份失败返回业务原因供 T3C-03 单独记录。
6. 定义 T5 后续接入所需的结果/计算版本与原报告引用，当前只保留关系，不宣称更正重算或受影响报告已实现。

数据契约与状态：

- 报告数据包为该次生成的稳定快照，旧报告不因当前目录、参数或结果更新被静默改写。
- “缺少可评价 CV”是业务状态，不等于文件生成失败；两者要区分。
- 本阶段不开发管理员更正；T5 将以共同数据版本接口使单份和批量读取相同有效结果。

## 4. 本卡不做与禁止事项

- 不复制月报计算公式，不改 Z-score 以 run 为最终判定的口径。
- 不将预留版本字段说成“报告受影响检测已完成”，不要求先完成账号才能做常规月报。
- 不修改既有质控公式、规则阈值或 Z-score 整次检测判定粒度；任务 0 的适用性继续精确判断。
- 界面不得显示编程语言、代码、开发说明、内部字段或错误堆栈；使用实验室业务用语。

## 5. Given–When–Then 验收

1. Given 同一 LJ 批次/月及相同有效版本；When 分别逐份和批量生成；Then 统计、质量要求与追溯内容一致。

2. Given 三水平 run 只有一水平失控；When 两种方式生成；Then 最终失控计数均为一次 run，各水平证据保留。

3. Given 生成期间参数或数据版本发生变化；When 保存；Then 重核或明确该项失败，不保存内容混杂的成功报告。

4. Given 无采用质量要求或数据不足；When 输出月报；Then 显示不能评价原因而不是 CV 达标，已确认临时隔离仍有效。

## 6. 证据与完成条件

- 同数据版本逐份/批量内容对照，跨参数版本、无法评价及 Z-score run 粒度案例。
- 报告版本合同与 T5 预留边界文档，受影响现有月报/报告历史回归。
- 证据逐条对应本卡验收编号，记录未执行项和失败原因；未通过不得勾选完成。
- 执行实现或验收时仅使用独立库/明确副本，记录版本和保护范围；此次编写卡片不运行应用或数据库操作。
