## 1. 目标与用户可见结果

## 2. 必读文件与复用入口

## 3. 逐步实施

1. 追踪现有LJ工作台数据准备及参数覆盖顺序，记录输入列/阶段/排除标记/参数的合同；不复制公式到新服务。
2. 在计算适配层构造按有效实测顺序排列的候选DataFrame，沿用现有正式/建靶阶段与参数来源，调用原算法。
3. 收集有效点数、均值、SD、CV、每点规则证据和结论；结果与候选数据版本绑定，不因暂时算完一部分就发布。
4. 连续规则需包括必要前置窗口并重算后续受影响点；原失控判读保留在历史版本中。
5. 对空序列、单点、缺适用参数、输入尺度错误输出沿用的明确不可评价/校验状态，不伪造正常。
6. 比较对照：用另一份隔离库按最终有效检测顺序正常录入，再用现有工作台读取；关键统计和逐点规则与候选重算一致。

## 4. 本卡不做与禁止

- 不改LJ公式、控制线含义、阈值或未经约定的纳入规则；本任务明确的管理员排除/恢复允许改变有效输入，并必须同步重算。
- 不只重算当前点，不在本卡写入当前有效版本。
