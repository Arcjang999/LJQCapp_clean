- 原需求锚点：[原任务 3B](../../task_03_comparisons_and_monthly_reports.md#3-3b试剂换批比对)；[合并需求](../../requirements_merged_2026_09_21.md) §4.5。

执行前阅读 [统一执行规则](../EXECUTION_RULES.md)。本卡是待执行范围，不表示功能已经实现。

## 1. 目标及用户可见结果

- 每一对结果都能核对计算方向、分母、条件区间及评价依据。
- 零分母、低浓度和不适用条件清楚显示不能评价，不出现无穷值或虚假通过。

## 2. 必读实际文件与复用函数

- T3B-01 方案合同、T3B-02 专门配对服务：计算只读已验证原始值。
- `services/quality_target_service.py::runtime_goal`：只读参考来源，不直接转成试剂阈值。
- `services/cv_service.py::calculate_cv_percent`：了解现有 CV 概念，不能作为配对差异公式复用。
- 拟新增专门比较计算函数和图表适配；服务与页面分离，不改 LJ/Z-score/即时法引擎。
- 所有业务搜索复用 `services/search_service.py::fuzzy_match / filter_frame`；选中后以稳定身份精确关联。

## 3. 逐步实施、数据关系与失败行为

1. 将方案版本作为计算显式输入，对每个样本保留旧/新原值、方向、差值和所用分母。
2. 按已确认公式计算相对差异，仅对有限且允许的分母计算；分母零返回不能评价及原因。
3. 按方案定义应用浓度区间或绝对差异条件，记录边界属于哪一段及闭开区间，不能隐含四舍五入后判定。
4. 样本量及浓度分布独立检查，逐对满足不等于整份方案条件已满足。
5. 绘制原始配对比较图与适用差异图，单位/方向/不评价点说明完整，图形不自动产生新的判定规则。
6. 计算结果绑定输入及方案版本；失败不保存部分评价，用户仍可查看原配对并修正后重试。

数据契约与状态：

- 示例仅用于测试：若已批准新减旧、旧作分母，旧 100 新 105 应为差 5、相对 5%；不是内置通用方案。
- 零分母只有明确方案允许时才能用另一种指标；禁止用极小数替换零或赋值“0%”。
- 阈值边界比较按方案原精度，展示精度不能反向改变结论。

## 4. 本卡不做与禁止事项

- 不自动套用 CV、TEa 或统一百分比；不为所有项目预设同一最低样本量。
- 不将 Ct/log 还原后混入首轮真实值配对，不修改日常质控算法。
- 不修改既有质控公式、规则阈值或 Z-score 整次检测判定粒度；任务 0 的适用性继续精确判断。
- 界面不得显示编程语言、代码、开发说明、内部字段或错误堆栈；使用实验室业务用语。

## 5. Given–When–Then 验收

1. Given 明确采用新减旧/旧分母的测试方案且值 100、105；When 计算；Then 差值为 5、相对为 5%，方向明确。

2. Given 旧值为 0；When 计算相对差异；Then 不输出无穷或通过，显示不能评价及方案是否存在适用绝对条件。

3. Given 值位于浓度分段/接受阈值边界两侧；When 评价；Then 按方案闭开区间和原精度选条件，结果可复算。

4. Given 每对都满足但样本量或分布不足；When 汇总；Then 明确条件不足，不自动通过整份比对。
