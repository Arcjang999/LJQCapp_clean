## 1. 使用流程

2026-09-22 本轮修订：用户明确只要现行依据。质量目标 → 分析质量要求按“检验项目要求”和“通用质控要求”分别检索，具体分子条目可按名称/别名找到；不再展示未生效/废止来源和参考区间。原先将94数值、5规则和2参考区间混计为101的展示已取消，历史数量不能解释成检验项目覆盖数。

项目新增/编辑中，在保存之前即按所选检验项目、方法学和单位展示数值及过程候选、依据类型和待补条件；保存后进入质量目标确认。运行新版源码即可使用，不以 commit/push 或安装包发布作为开关。启动器关闭文件热更新，已启动的进程须重启才能加载修改。

在检验项目或批次的“质量目标”弹窗中，先核对检测技术、定量/定性、结果尺度、检测用途、标本/基质。能从实际方法学明确识别的技术自动带入；修改方法学后必须重新核对。项目代码、完整名称、缩写及已核对别名用于准确查找候选，工作分组不决定标准。新增身份矩阵覆盖全部94条数值要求；不同基质、肌酸激酶-MB质量/活性及血糖仪方法不能因近似名称自动混用。

- 明确适用的数值标准默认选择，适用过程/定性条款同时带入。服务层禁止清空、遗漏过程标准、自由填写排除理由或采用较宽自定值后确认。
- 单位不匹配、方法不明确、条件缺失或多个数值来源未消除歧义时，保留待核查；不做单位换算，也不按任意排序裁决冲突。先纠正检测对象/条件、核对原文和来源，不支持用一段自由文本强行确认冲突。
- “保存待确认资料”保留条件、查找记录、补充来源及未完成的实验室文字要求。待确认资料不能启用配置；正式采用仍需确认人及适用依据。
- 当前目录未覆盖不等于不存在国家或行业标准。须登记查找词、官方链接、日期、复核结论和理由；有适用过程条款时不能选择“无适用标准”。
- 发现未收录标准时，登记编号、名称、版本、实施/废止日期、官方全文链接、条款页码、要求、核查人和适用依据，并上传标准全文PDF；校验值由软件内部生成，界面不再要求用户手填技术校验值。补充条款仅记录，不自动生成数值评价器；参考区间和未生效/废止标准不能登记为现行质量限值。
- 实验室可在标准基准上补充更严的正数 CV，保留原标准、所选水平规则和补充依据。补充值必须严于每个适用 CV；不能把 SD 与 CV 比大小。

HIV-1 RNA定量需在项目输入类型和结果尺度两处选择log，并实际输入已经换算的Log10结果。原浓度或Ct状态下仍展示专项依据并要求先核对，不能直接确认；软件不自动转换原数据。定性Ct不生成浓度CV；准确HIV-1 RNA身份及方法核对与模糊搜索分开。

确认只表明已登记采用依据，不代表实验室已经完成标准的全部要求，也不代表患者报告获准放行。WS/T 是卫生行业推荐性标准；必选是本软件的配置规则。
