# 常规业务快速上手

本说明介绍常规室内质控的日常操作。软件内可从“帮助 → 使用说明”查阅完整步骤，也可阅读 [软件使用说明](current_user_guide.md)。

## 启动并选择项目

双击项目根目录的 `启动质控软件.command`，等待浏览器打开“项目工作台”。保留项目和旁边的 `.venvs` 文件夹，启动窗口保留打开；关闭窗口会结束服务。无需压缩或打包。

已有检测记录按2026年9月28日查询，新录入按实际日期查询。详细项目与操作顺序见 [操作说明](OPERATION_GUIDE.md)。

首页可按项目名称、分组或仪器搜索，并按分组、仪器筛选。找到项目后进入，再选择需要的检验项目或打开“整组录入”。

同一项目可包含使用LJ、多水平法或即时法的检验项目。每个检验项目分别设置质控方法及真实检测值、Ct或log输入类型；选择多水平质控品不会自动选择或更改质控方法。

## 第一次准备自己的资料

### 实验室、厂家和仪器

1. 在“系统设置”填写实验室及报告信息。
2. 打开“资料与批次 → 厂家管理”。厂家按仪器、试剂、质控品分类；新增或编辑时至少选择一类，同一厂家可以兼属多类。
3. 打开“仪器管理”，点击“新增仪器”。在同一弹窗填写仪器名称、厂家、型号及设备资料后保存，无需先登记型号。同型号的多台仪器分别登记，各自保留名称和关联项目；实验室信息沿用系统设置。

### 试剂产品和批号

1. 打开“资料与批次 → 试剂管理”，在产品列表点击行首选择框，进入所选产品。
2. 核对产品名、厂商和货号，在下方“批号管理”登记实际批号。登记时产品已确定，无需再次选择。
3. 选中具体批号后，再进行验证或换批。需要管理其他产品时，点击“返回试剂列表”。

### 质控品和适用检验项目

打开顶部“质控品管理 → 产品名录”。邦德盛1054项产品可直接选用，表中显示厂商、产品编号、产品名称、浓度和浓度编号。“基础资料 → 质控品与批号”也可访问同一名录。

1. 按厂商筛选或搜索产品，单选行首选择框后仍留在名录。新增、编辑、停用在主页面完成。
2. 点击“管理批次”，在弹窗查看或登记实际批号、效期和各水平；关闭后回到原名录位置。
3. 点击“查看／管理关联项目”，在独立弹窗核对适用检验项目及关联项目。
4. 点击“选择检验项目”，按名称、编号或别名搜索并勾选，更换搜索词后原选择保留。
5. 点击“确认选择”带回草稿；填写核对人、参考资料后，点击“保存适用项目”才保存。

### 项目和批次设置

1. 新建项目时，点击“从产品名录选择”，核对后点击“使用此目录产品”。
2. 保存项目后，用“整组添加检验项目”从已有项目或“质控品适用检验项目”带入，也可自行选择检验项目。
3. 逐项核对方法、尺度、单位、试剂、水平和质量要求。导入配置文件时先预览，导入后仍须核对是否适用。
4. 确认实际批次、各水平参数、依据、验证和使用时间。明确适用的标准须采用；没有适用CV、数量不足或只有过程条款时，不能视为已达标。

## 在所选项目内整组录入

打开项目内“整组录入”，沿用该项目、仪器和质控品，选择实际批号或完整材料组合，再展开表格。

填写检测时间、检测人和本次各水平数值。Enter、Tab只移动输入格，不会保存结果。粘贴或导入结果文件时，先预览，再带入录入表。粘贴前按当前页面核对实际水平行数和顺序；多水平一次检测不能缺水平。

依次点击“核对并保存”与“确认保存整组”。任何一项错误都会阻止本次整组保存，已填写内容保留，修改后可再次核对。保存成功后核对各项结果；重复确认不新增记录，下次检测点击“再次检测，开始新一组”。

打开设置后返回录入页，可继续填写。关闭应用或强制刷新前，先保存需要保留的结果。

“今日质控总览”可查当日及跨日未完成处理；最新在控不消除当日曾失控，多水平按完整检测计次。

## 处理异常并归档报告

从异常原记录登记原因、措施、效果和患者影响评估，关联同检测系统的实际复测，核对差异并加入附件。附件随处理记录保存归档。

先保存草稿，再提交效果确认，由人工确认完成；复测在控不自动完成处理。可查看处理历史和已保存的PDF。

打开“批量月报”，选择月份，核对可生成报告及未纳入项目的原因后，再选择生成。一份失败不影响其他成功报告，可单独重试失败项。可下载原PDF或完整清单，查看对应报告历史；按当前资料重新生成会另存新报告。

CV按批次、参数版本和水平分别评价，不跨版本混算。此页不提供即时法月报或临时质控月报。

## 备份和当前边界

在“系统设置”创建完整备份，保留数据库、附件和报告；含外部附件时不要只复制数据库。恢复会替换当前资料，先核对备份文件和时间；更换保存位置后按提示重启。

按各页面登记资料、录入常规结果、处理异常并生成月报。临时质控、质控品新旧批比对和患者样本试剂比对须另按实验室流程开展；本软件暂不提供相应专用操作。已保存检测值不能通过修改批号设置来更正。
