# 质控品规格、项目分类与批次组合：整条流程核查

日期：2026-09-20。状态：本文保留实施初稿前的链路核查与问题定位。目前已有未验收的流程代码初稿；最新业务层次、即时法位置、弹窗交互及开发顺序以 [项目中心流程与弹窗交互改造计划](workflow_ui_refactor_plan.md) 为准。下文“当前代码事实”对应核查时状态，不代表每个问题至今完全未改。

用户最新口径：浓度水平和浓度编号分为两个字段；质控品批号与水平登记合并；新建项目需要体现单水平/多水平与检测方法学，并核查前后整条流程。此前质量目标入口调整及三阶段任务文档保留。

## 1. 明确区分的内容

| 内容 | 所属对象与用途 | 不应混用 |
|---|---|---|
| 浓度水平 | 质控品浓度规格的名称，例如低值、高值、厂家 Level 2；允许厂家原文 | 不等于某次 Z-score 组合中的第几个位置 |
| 浓度编号 | 该产品浓度规格的标识，按文本保存，保留前导零和字母 | 不当成数值浓度、检测结果或系统自增顺序 |
| 产品货号 | 厂家订货标识；不同浓度规格可能有独立货号 | 不等于生产批号或浓度编号 |
| 实际批号、效期 | 当前具体质控材料的批次资料 | 不要求所有水平拥有同一个实际批号，也不把内部组合编号冒充厂家批号 |
| 检测方法学 | 检验项目采用的检测原理或方法，关联适用仪器、试剂与单位 | 不等于 LJ、Z-score 或即时法 |
| 质控方式 | 当前软件支持单水平 LJ、多水平 Z-score、即时法；决定工作台与判读流程 | 不由厂家浓度名称或编号自动决定 |
| 本次使用水平数 | 该检验项目配置实际选用的水平数量 | 不等于质控产品全部浓度规格数量 |
| 厂家赋值、均值、SD | 按检验项目、适用方法、具体质控批次和参数版本保存 | 不把产品规格编号当成赋值，也不把新批直接视作沿用旧参数 |

“单水平”表示本次选择一个质控材料，选择高值或厂家 Level 3 也可以；不是只能使用厂家编号为 1 的材料。Z-score 继续使用 2/3 个水平并按整次检测判定，即时法仍为单水平及现有 3/20 点规则。

## 2. 已查实的断点

| 环节 | 当前代码事实 | 需要调整 |
|---|---|---|
| 质控品资料 | `md_qc_materials` 只有通常水平数等基本资料；水平名称、`level_code`、浓度说明保存在批号下的 `md_qc_levels`。`level_code` 已存在，但截图中的登记表未提供输入 | 形成可复用的产品浓度规格，界面显示浓度水平与浓度编号两个字段；不只在批号表单临时添加两个输入框 |
| 批号登记 | `pages/master_data_page.py` 分别调用 `create_qc_lot` 与 `create_qc_level`，需要两次提交 | 同一入口登记产品浓度规格、实际批号与效期，一次完整保存；失败时整次回滚；保留同号多水平旧资料 |
| 新建项目 | `_render_template_creation` 创建的是仪器与质控品下的一组检验项目配置，首屏不包含质控方式和方法学 | 首屏呈现分类选择和后续继承关系；明确项目分组与具体检验项目的含义 |
| 添加检验项目 | 质控方式、方法学、输入值类型、单位、水平数在后续批量添加时才出现；方式与水平数可先形成矛盾输入再在保存时处理 | 添加时带入默认值，显示每项最终生效设置；单水平/即时法固定一个位置，Z-score 提供 2/3 个位置 |
| 候选分类 | 新建项目的仪器、试剂、质控品直接读取全量启用字典；添加检验项目的单位、方法学也读取全量字典，未建立这些选择之间的适用关系筛选 | 将列表分类与业务适用关系分开设计。有明确适用关系时用于筛选；未维护时标明待核对，不能仅按名称猜测匹配并排除其它候选，也不能把 LJ/Z-score 当成检测试剂分类 |
| 项目选择与分类 | 项目选择标签主要是名称、仪器、项目数和状态，未体现质控方式和方法学，也未提供相关筛选 | 列表与选择器可按质控方式、方法学筛选；混合项目需要明确标为多种，不能只拿首项代表整组 |
| 首次建立批次 | `create_lot_config_from_template` 接收一个质控品批号；水平编辑器只列该批号下的材料；`save_lot_item_levels` 限同批号或已登记的特殊组合成员 | 首次创建即可逐水平选取实际材料与批号，不必先构造同批号的多水平假资料，再从换批入口绕行 |
| 部分水平换批 | `create_level_combination` 已支持同一质控产品的不同批号，但校验 `md_qc_levels.level_order == 组合位置` | 产品浓度标识与组合位置分开；按对应的材料规格检查替换关系，不能简单删除校验后允许任意错配 |
| 工作台衔接 | LJ、即时法来源查询仍检查水平属于配置主批号；Z-score 额外接受组合成员 | 逐项使用实际选定材料，核对三方法来源、同步、身份与冻结快照，不能只修改管理页选择器 |
| 工作台显示 | 单水平浓度显示使用名称/浓度说明，多水平拼接水平名称；新建配置的部分摘要仍只有主批号 | 连贯显示产品、浓度水平、浓度编号、各自实际批号及效期；多水平组合不显示成一个厂家批号 |
| 导出与追溯 | 配置水平查询已有 `level_code`，配置快照已有实际水平批号；仍需核对所有消费者。结果上下文单独保存各水平实际材料；月报已有追溯资料 | 编号、名称及实际材料关系进入新的配置与检测快照，并贯穿配置导出、记录追溯、新生成报告；旧报告和原判读不回写 |
| 质量目标 | 按检验项目来源及批次各水平确认；条件浓度/类别用于挑选适用要求 | 带出明确材料身份供核对；不能用浓度编号或组合位置推算浓度数值或厂家低/高界限 |

## 3. 推荐的完整操作链

1. **登记质控品及浓度规格**：产品系列下维护浓度水平、浓度编号，必要时维护规格货号。不同浓度不要求重复输入所有厂家与产品资料。
2. **登记实际材料**：选择产品与浓度规格，录入实际批号、效期，一次保存。新增规格可在当前操作中完成；不要求先退出新增批号再进入新增水平。
3. **新建项目**：选择仪器、质控产品及试剂，明确质控方式和检测方法学；具体检验项目的单位、输入值类型和最终方式保持可见。
4. **选择本次使用的质控材料**：单水平/即时法选择一个实际材料；Z-score 选择 2/3 个材料，各自显示浓度水平、编号、批号、效期。允许低值为 A 批、高值为 B 批，也兼容厂家同号多水平资料。
5. **确认参数及质量目标**：按实际材料对应的检验项目配置分别保存厂家参考/实验室均值、SD 和目标适用条件。资料确认、参数确认与实际使用状态继续分别表达。
6. **进入对应工作台**：按最终质控方式路由；录入、图表、质量目标比较和报告使用同一组冻结的实际材料身份。
7. **换批**：可仅换低值 A 为新批 A2，高值 B 保持不变；新组合及适用参数重新确认，旧检测保留 A+B 身份，不被 A2+B 覆盖。

## 4. 项目分类选择（已确认）

用户已确认保留同一项目内混合不同质控方式/方法学的能力：“先设默认再逐项调整”。

确定方案是“新建时设默认，检验项目逐项确认”：默认选择减少重复填写，逐项配置是最终依据。项目摘要与筛选必须依据实际检验项目，而不是只依据默认值。旧项目中已经存在的逐项配置继续有效；不能迁移时统一覆盖。

不自动拆分混合项目，也不改写已有批次及检测记录。主入口按项目/检验项目进入；工作分组和方法学不自动决定 LJ 或 Z-score。即时法在单水平参数建立过程中由用户选择，细节见最新计划。

质控方式不放到质控产品规格上：同一高值材料可以单独进行 LJ，也可以与另一个材料组成多水平质控。

## 5. 实施顺序与数据边界

1. 按已确认的默认带入/逐项调整及最新计划，完成产品规格与实际材料的数据关系；为已有记录保留原 ID、引用和快照。
2. 合并批号/水平登记，建立完整事务与重复登记校验；有可靠旧编号则保留，没有则留空，不从旧顺序生成厂家编号。
3. 改新建项目、项目摘要/筛选及检验项目继承；方式变化同步约束本次使用水平数。
4. 改首次批次选择、后续换批及完整材料校验，并贯穿三方法绑定与即时法转 LJ。
5. 补齐工作台、质量目标、导出及新报告显示；检查历史查询与已停用材料仍可追溯。
6. 在独立数据库进行迁移及端到端验证，验收后再按用户工作流处理实际库更新。

不能以“界面合并完成”代表整条链已完成。既有质控判读算法不因资料结构调整而改动；保留原批次的均值/SD 版本、质量目标采用副本、检测结果与报告历史。

## 6. 必须覆盖的验收场景

- 同一产品低值与高值分别拥有不同编号、不同批号和不同效期，首次即可建立 Z-score 配置。
- 同一实际厂家批号对应多个水平的旧数据仍可使用和追溯；相同批号文本在不同产品/规格下不会误合并。
- 厂家高值或 Level 3 单独用于 LJ/即时法，不要求用户把产品编号改成 1。
- 编号如 `001`、`L02` 按文本原样保存、导出和显示，不变成数字浓度。
- 浓度规格数量不限制某项目只选一个或其中两个；组合中不允许重复选择同一实际材料。
- Z-score 的 2/3 水平必须完整；任选材料后顺序稳定，单次记录、图表、质量目标和报告对应一致。
- 如果保留混合项目，默认设置变更不覆盖已保存逐项设置；项目分类筛选能找到混合项目，工作台仍按实际方式路由。
- 新批次不能绕过效期、停用状态、材料匹配、参数确认和质量目标逐水平确认。
- 只更换一个材料后，旧序列和旧报告仍显示原材料；未更换材料的参数引用保持正确。
- 合并登记任一字段无效时不留下空批号、半条规格或重复水平；失败输入可修正后重试。
- 旧库迁移重复执行无副作用；未知浓度编号不补造；原检测行及历史快照保持不变。
- 导入导出、备份恢复、即时法转 LJ、配置停用/恢复均保留材料身份；实际浏览器走完从资料登记到首条检测再到换批的路径。
