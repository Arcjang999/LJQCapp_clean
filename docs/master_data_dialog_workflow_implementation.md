## 本步完成范围

从“资料与批次 → 基础资料”进入，厂家、检验项目、仪器、试剂、方法学和单位统一使用搜索列表、所选记录详情，以及新增/编辑弹窗。主页面不再常驻新增表单。

- 仪器分为“已登记仪器”和“仪器型号”，先维护型号，再登记实际使用的仪器；两者都有独立编辑入口。
- 方法学与单位分开维护。检验项目保留按代码、名称和启用别名搜索；在所选项目下新增、编辑、停用或恢复别名，不能把别名改到另一个项目。
- 保存失败保留填写内容；回车只确认文本输入，不提交整条资料。取消有修改时可继续编辑或放弃，继续编辑保留输入。
- 保存后保持选中记录；原搜索仍能匹配时保留搜索，改名或新增后不匹配时清除搜索以显示刚保存的资料。修改用于搜索的项目别名后仍回到父检验项目。
- 停用和恢复都打开确认弹窗；停用须填写原因，只有点击最终确认才写入。基础资料使用一次确认，用户此前要求的项目停用两次确认不变。
- 离开基础资料再返回，保留类别、子页签、搜索、显示停用选项与所选记录。筛选隐藏当前记录后，编辑和停用按钮不可操作该隐藏记录。
- 质控品与批号沿用已完成的界面。页面统一调度弹窗，若有两个待处理草稿，也只显示一个，另一草稿保留。

名称沿用 [界面用语与手册对照](ui_wording_manual_alignment.md)，继续使用“厂家、仪器、试剂、检验项目、方法学、单位”。不把数据库表名或程序对象名显示为业务名称。

## 数据保护与代码结构

`pages/master_data_page.py` 只组织类别与子页签；`ui/master_data_workspace.py` 负责列表和详情；`ui/master_data_dialogs.py` 负责输入与确认；`services/master_data_edit_service.py` 负责编辑校验，复用既有新增和停用服务。没有新数据库迁移或计算规则。

系统收录资料的名称和代码等不能直接修改，可维护备注。已经被项目、草稿、停用记录、仪器、试剂批号、质控品或来源记录使用的身份字段受保护；仪器的科室、仪器组和位置仍可维护。历史配置及结果快照不改写。新增或改选关联资料时只能采用启用项，原有停用关联可保留，避免仅补充备注时破坏旧资料。

编辑和状态确认读取完整记录指纹，在同一事务内检查后写入；资料已被其他窗口更改时拒绝覆盖。重复名称、代码、别名或恢复冲突显示可理解的错误并回滚。没有硬删除入口。
