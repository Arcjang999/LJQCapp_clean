# 项目模板的仪器、试剂和质控品选择

日期：2026-09-11。依据用户最新口径增量调整 V1.1 模板入口。

## 行为

- 新建模板同时必选本地仪器、试剂、质控品，均引用基础资料中启用的字典记录。
- 模板试剂保存为 `qc_project_templates.default_reagent_id`，是新增检验项目时的预填值。多项目模板中，每个检验项目仍保存自身的 `reagent_id`，允许分别选择试剂。
- 旧模板通过“模板默认试剂”补选；修改默认值只影响后续新增项目，不覆盖既有项目、批号配置或配置快照。
- 无有效默认试剂时，新增项目的试剂保持空选，需明确选择才能添加；停用产品不出现在新选择中。编辑已有项目遇到不可用试剂时提示重新选择，拒绝静默清空原关联。
- 新建页面的三项必选不追溯阻断旧模板；服务创建接口保留可空参数以兼容已有调用，项目启用校验继续要求每个项目配置试剂。
- 导出模板信息包含默认试剂及厂家；导入仍按项目配置中的试剂逐项解析，不用模板默认值覆盖导入内容。
- 内置字典有检验项目、单位和方法学，尚无真实仪器、试剂及质控品产品目录。空字典提示用户先维护资料。

## 数据迁移

`migrations/v1_2_template_reagent.py` 由 `init_db()` 在 V1.1 建表后调用。幂等增加可空外键列并登记迁移，不自动从已有项目推断默认值。测试覆盖旧表重复迁移、完整性、默认值传递、逐项覆盖、停用拒绝、历史快照保留及未修改表格保存。

## 设计依据与范围

以下是对公开资料的概括，不构成 ISO 15189 符合性声明，也不把软件表单布局描述为标准原文要求。

- [ISO 15189:2022 官方介绍](https://www.iso.org/standard/76677.html)：该标准规定医学实验室质量和能力要求。
- [NATA 的 ISO 15189:2022 条款对照说明](https://nata.com.au/files/2023/03/SAG_11_2_ISO_15189_2022_Gap_Analysis.pdf)：6.4.7 涉及设备记录，6.6.3 涉及新试剂批次等使用前的性能验证，6.6.7 涉及试剂记录，7.3.7.2 涉及室内质控。它们支持管理检测条件及追溯信息的产品方向，并不指定“项目模板”数据库结构。
- [Westgard：Method Validation in the Real World](https://www.westgard.com/qc-applications/method-validation-qc/qcapp14.html)：强调记录试剂批号、校准、维护和方法变更等条件，并在检测方法应用中选用适当质控品。

本次完成产品字典关联与模板默认值。试剂产品与试剂批号是不同层次；逐次检测关联试剂批号、新批验证和完整设备管理需后续单独建设，不能因已增加下拉选项就称已满足全部标准要求。
