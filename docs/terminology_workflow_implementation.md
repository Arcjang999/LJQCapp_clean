## 2. 换批全过程结果与入口修复

### 可复现场景与修复

先从“更换质控品批次”建立待确认新批，再到“新旧批号比对”选择同一新批时，原入口仍呈现创建表单；既有服务会拒绝重复启用已包含的检测项，用户不容易找到已建批次。

现在选择目标批号后，若同项目已有普通批次，显示“打开已有新批次核对”，跳至“批次管理”并选中该批次。核对并确认设置后，可为同一批次登记同时使用。若新批仅启用了部分检测项，仍允许将尚未使用的其余检测项加入同时使用；没有新增第二套换批服务。原有创建新批后自动跳转的行为保留。

### 数据与状态链路

| 核查项 | 当前结果 |
|---|---|
| 旧批继续使用、新批自行积累 | 新批具有独立运行批次；旧批结果不并入新批。 |
| 同时使用转正式使用 | `set_qc_usage_state()` 记录状态事件；不另建空批。切换前后批次 ID、原始结果、来源上下文、已保存判读一致。 |
| 均值和标准差适用性 | 人工/厂家参数复制后仍待重新确认；本批次计算从新批数据建立。显式正式使用需要关联实际批号的适用验证；LJ/Z-score 还检查控制参数条件。 |
| 旧批停止使用 | 原记录保留；停止使用生效后的新增检测被拒绝。 |
| 同产品换批与更换产品 | 当前换批入口只选择同质控品产品的其他批号；更换产品需另建项目，不把不同产品当作同产品换批。 |
| 混合水平与部分检测项 | 现有部分水平组合、逐实际批号验证保持不变；既有边界测试通过。 |
| 专门新旧批比对 | 目前只能分别查看两批统计、曲线和月报，并管理同时使用状态。没有新旧批同时间段专门计算、合并比对图或比对报告；页面明确此边界。 |
| 试剂换批比对 | 现有试剂换批记录与验证依据登记不等于患者样本配对比对；专门功能仍属第 4 节后续任务。 |

## 3. 代码与标准对照：本轮未改变统计方案

本轮重新查阅国家卫生健康委发布的 [WS/T 641—2018《临床检验定量测定室内质量控制》正文](https://www.nhc.gov.cn/wjw/s9492/201812/f71376353f5d409593c2bc57d01f1ea0/files/1739781543096_36831.pdf)，重点为第 5.1、5.2、5.3.4 节。以下为特定条款与当前实现的对照，不表示全应用已符合该标准；其他 GB/T、JJF 正文的已查/待查范围仍以原[术语与业务口径文档](terminology_and_workflow_alignment.md)为准。

| 项目与适用对象 | 标准要点（释义） | 当前实现与差距 | 后续具体改法 |
|---|---|---|---|
| 稳定性较长质控品：独立分析批，5.1.1.1、5.2.1.1 | 暂定均值/标准差的建立涉及不少于 20 个独立分析批及不少于 20 个结果。 | `qc_logic.py` 按有效点选取；Z-score 的 `build_level_target_profiles()` 按各水平有效结果选取。一个 run 不能自动等同标准中的独立分析批；当前未建独立分析批标识及去重计数。 | 明确同批重复测定如何归属，增加分析批记录/关联，分别展示分析批数与结果数；保留旧记录无法确认归属的状态。 |
| 稳定性较长质控品：暂定与常用参数，5.1.1、5.2.1 | 随持续积累约 3–5 个月的资料更新并确定常用参数。 | 已有带生效时间的参数版本，但没有暂定/常用参数生命周期与周期复核。Z-score 的 `provisional_*` 是达到点数阈值前的滚动统计，不能据名称视作上述标准方案已实现。 | 在现有参数版本上增加适用阶段、复核窗口、纳入依据和人工确认；旧判读仍使用当时版本。 |
| 稳定性较短质控品：均值，5.1.2 | 按较短稳定期设计重复测定、瓶间/日间方案。 | 项目/批次没有质控品稳定性分类、瓶号及对应统计方案；仍使用通用有效点计算。 | 先确定适用产品与实验室 SOP，再增加稳定性分类、采样计划、瓶/日关联及专门统计。 |
| 稳定性较短质控品：标准差，5.2.2 | 可利用适用的长期变异系数资料建立标准差，涉及历史或加权资料的适用性。 | 可人工确认均值/标准差并记录依据，但没有历史 CV 汇总、加权、来源选择及自动推导流程。 | 明确历史资料范围、水平/浓度匹配、加权与审核规则；保留采用记录及公式，不能直接复制旧批结果。 |
| 新旧批衔接，5.3.4 | 旧批用完前安排新旧批同时使用，独立确定新批适用均值和控制限。 | 已具备独立批次数据、同时使用、参数确认和正式使用/停止使用事件；完整统计方案与专门比对报告仍有上述缺口。 | 保留现有生命周期；后续在其上补分析批及参数方案、专门比对视图，不重建另一套批次对象。 |

本轮未修改即时法 3 点开始检验、20 个有效点人工确认转入 LJ 的既定产品规则，也未全局将点数替换为独立分析批数。实质统计变更应先明确适用对象、采样设计和迁移口径，再逐项落地。
