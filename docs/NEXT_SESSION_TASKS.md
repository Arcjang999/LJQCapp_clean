### 2.1 任务 0：标准扩展及适用标准必选（下一开发项）

完整规格、官方来源和验收样例见 [任务 0](task_00_standards_expansion.md)。按以下顺序交付：

1. **来源与适用条件清单**：核对 403 已有免疫覆盖；复核 230/494 官方全文、现行/替代关系和具体条款。记录名称、版本、生效时间、条款/页码、方法、标本、结果尺度、单位、浓度及用途，区分已证实和待核对。
2. **服务校验与兼容存储**：在现有质量来源服务上增加条件判断和多种依据关联。明确适用必须采用；信息不足只能保留待确认草稿；目录未收录不得直接当作没有标准。阻止空来源、任意排除理由或较宽自定要求绕过。保留旧已确认批次及历史报告的原来源。
3. **检验项目和批次弹窗**：选择检验项目后展示适用依据及待补条件，项目和批次确认前完成采用；过程/定性条款与数值 CV 分开。相关字段使用已确认业务用语。

下表保留9月15日确认的业务边界。其中质量目标首版已完成，附件并入任务 1，失控报告对应任务 1，试剂换批配对比对对应任务 3，试剂换批操作及使用事件更正弹窗已完成。历史检测实际批号更正仍是已选后续需求，但不为凑齐功能而插入三阶段的关键路径。独立分析批、暂定/常用参数、长期/加权 CV 等已有差距另列后续统计方案，不能因完成体验改进就标为已实现。

| 功能 | 具体交付与验收边界 |
|---|---|
| 历史检测记录批号更正 | 从某次检测进入更正，保存原批号、新批号、原因、更正人及时间；更改当前默认批号不能回写旧结果。质控品批号更正若影响参数和判读，须明确核查和更正处理，不能静默改写原判读 |
| 上传附件 | 放在换批验证或失控报告中，保存已有表格、扫描件等；支持查看/下载并纳入备份恢复。上传不代表计算或验证通过；文件格式、大小及保存方式属于待实现细节，无需单独业务入口 |
| 试剂换批比对 | 录入同一患者样本用两批试剂得到的成对结果，计算差异并输出报告；按明确的适用标准或实验室方案判断。与两批不同质控材料的新旧批号比对分开，不扩展为通用性能验证平台，不预设万能合格阈值 |
| 质量目标 | 403/406 共 94 条及 CV 比较首版已完成；任务 0 扩展来源、适用条件及必选校验。WS/T 886 名称代码不等于质量限值；SD/偏倚/TEa 尚不自动评价，TEa 不能直接当 CV 上限，旧批次保留原采用要求 |
| 失控原因分析与报告 | 从原失控记录填写原因分析、纠正措施、复测结果、处理效果和必要的患者结果影响评估，保存/查询/导出失控报告；保留原失控记录，不以“处理完成”覆盖原判断。填写确认人不等同引入权限与电子签名系统 |
