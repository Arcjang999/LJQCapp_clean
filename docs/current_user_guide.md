# 质控软件使用说明

首次使用从第一项开始；日常工作选择需要的操作。软件**帮助 → 使用说明**按这些章节展开，完整步骤见[操作说明](OPERATION_GUIDE.md)。

| 顺序 | 操作 |
| --- | --- |
| 1 | **[首次使用](OPERATION_GUIDE.md#首次使用)** |
| 2 | **[从Excel批量登记资料（选用）](OPERATION_GUIDE.md#从excel批量登记资料选用)** |
| 3 | **[新建单项项目](OPERATION_GUIDE.md#新建单项项目)** |
| 4 | **[设置质量目标](OPERATION_GUIDE.md#设置质量目标)** |
| 5 | **[验证并使用试剂批号](OPERATION_GUIDE.md#验证并使用试剂批号)** |
| 6 | **[录入单项结果](OPERATION_GUIDE.md#录入单项结果)** |
| 7 | **[整组录入结果](OPERATION_GUIDE.md#整组录入结果)** |
| 8 | **[建立均值和标准差](OPERATION_GUIDE.md#建立均值和标准差)** |
| 9 | **[即时法转入 L-J](OPERATION_GUIDE.md#即时法转入-l-j)** |
| 10 | **[设置多个检验项目](OPERATION_GUIDE.md#设置多个检验项目)** |
| 11 | **[查看和维护记录](OPERATION_GUIDE.md#查看和维护记录)** |
| 12 | **[处理失控并关联复测](OPERATION_GUIDE.md#处理失控并关联复测)** |
| 13 | **[导入导出数据和质控图](OPERATION_GUIDE.md#导入导出数据和质控图)** |
| 14 | **[生成质控报告](OPERATION_GUIDE.md#生成质控报告)** |
| 15 | **[查看原报告和完整备份](OPERATION_GUIDE.md#查看原报告和完整备份)** |
| 16 | **[常见问题](OPERATION_GUIDE.md#常见问题)** |

首次引导按**实验室信息 → 仪器试剂管理 → 新建项目**操作。仪器、试剂和质控品可逐项登记，也可从**资料与批次 → 单位资料准备**批量导入Excel。新建项目时缺少批号，可直接点**登记质控品批号**，保存后继续选择各水平。保存检测后，到检测记录和质控图核对结果。
