# 软件使用说明

更新：2026-09-28。在软件顶部打开 **帮助 → 使用说明**，可按操作展开查看。本文覆盖当前常规业务。已配置项目的具体操作见 [操作说明](OPERATION_GUIDE.md)，简版步骤见 [常规业务快速上手](ROUTINE_VERSION_QUICKSTART.md)。

## 从项目工作台开始

1. 在首页“搜索项目”输入项目名称、分组或仪器，也可按“分组”和“仪器”筛选；勾选项目行首选择框进入。一个项目可以包含多项检验项目，各项分别配置并显示方法，可混合单水平（LJ）、多水平法、即时法和不同输入类型。
2. 需要一起录入时，点击所选项目内的“整组录入”。页面沿用这个项目、仪器和质控品，再选择该项目本次实际批号或完整材料组合；不混入其他项目的检测项。
3. 只查看一个检验项目时，选择该项及已确认批次，点击“进入当前批次”，查看其质控图、记录和单项操作。
4. 首页不需要另选质控方法。方法来自各检验项目已确认的配置；产品包含多个水平，不代表必须使用多水平法。更换或导入产品也不会替换已经选择的方法。
5. 需要帮助时打开顶部“帮助 → 使用说明”；看完点击“返回项目工作台”继续操作。

项目和基础资料页面的搜索支持部分名称和多个关键词；检验项目可按已登记别名查找。搜索只帮助定位，批次、单位、标准和检测项仍须核对准确。

## 首次准备：实验室与基础资料

在“系统设置”填写实验室、科室及报告默认信息。检验项目、方法学和单位在“资料与批次 → 基础资料”维护，先搜索已有资料，未找到时再新增。

### 厂家：按产品类别登记

入口：**资料与批次 → 厂家管理**。

1. 选择“仪器厂家”“试剂厂家”或“质控品厂家”，查找已有厂家。
2. 新增或编辑厂家时，填写名称并勾选业务类别，至少选择一类。
3. 一个厂家经营多类产品时，可同时勾选多个类别，保存后可在相应类别下找到。

### 仪器：一次登记一台实际设备

入口：**资料与批次 → 仪器管理**。实验室信息沿用“系统设置”中的内容。

1. 点击“新增仪器”，在同一个窗口填写仪器名称、厂家、型号及资产编号、序列号、所属科室、放置位置等资料，再保存。型号直接在这里填写。
2. 同型号有多台设备时，每台分别登记，用不同的仪器名称、资产编号或序列号区分。
3. 在列表选择仪器，查看“此仪器下的项目”；在“打开关联项目”中选择项目，再点击“进入所选项目”。
4. 修改资料时先选择仪器，再点击“编辑仪器”。已经用于项目的厂家和型号按页面提示保留，位置、科室等可继续维护。

### 试剂：产品下面管理批号

入口：**资料与批次 → 试剂管理**。

1. 在试剂列表中单选产品，可点击“编辑试剂”或“停用试剂”；“新增试剂”也在同一操作栏。已停用产品勾选“显示已停用试剂”后可恢复。点击“管理批号”进入所选产品，核对产品名、厂商和货号，需要时展开“产品资料”。
2. 在当前产品的“批号管理”点击“登记试剂批号”，填写实际批号、效期等资料，再点“保存试剂批号”。登记窗口已选定当前产品。
3. 选择具体批号，点击“登记批号验证”，按检验项目填写验证结论、依据、完成时间和确认人，再点“保存验证记录”。
4. 需要启用新批号时，点击“切换到此试剂批号”，选择本次切换的检验项目。核对新旧批号、验证结论和实际启用时间，填写原均值和标准差仍适用的依据，最后点击“确认切换所选检验项目”。
5. 管理其他产品时，点击“返回试剂列表”，原搜索和选择会保留；重新单选产品，再点击“管理批号”。

页面提示没有可用检验项目时，先核对项目和批次设置。切换批号只调整所选项目的使用安排，既往检测保留当时的实际批号。

## 质控品管理

### 在质控品名录中选择和维护产品

入口：顶部 **质控品管理**，主页面为“质控品名录”。“资料与批次 → 基础资料 → 质控品与批号”也可访问同一份资料。

1. 按厂商筛选，或搜索产品编号、名称、浓度、浓度编号。已确认的邦德盛1054项产品可直接选用。
2. 核对表中的**厂商、产品编号、产品名称、浓度、浓度编号**，单选一个产品。选中后仍留在名录，需要留存名录时点击“导出产品清单”。
3. 在主页面点击“新增质控品”登记新产品；选择已有产品后，点击“编辑质控品”修改资料，或点击“停用质控品”停止使用。已停用的质控品可在主页面恢复。
4. 选中产品后，点击“查看／管理关联项目”，在弹窗中维护“适用检验项目”，并查看使用这款质控品的项目。
5. 点击“管理批次”，在另一个弹窗中维护所选产品的实际批号和水平。

关闭管理弹窗后，名录保留原来的搜索条件和选中产品。有未保存修改时，先确认是否放弃修改。

### 在批次弹窗中管理实际批号

1. 在“质控品名录”单选产品，点击“管理批次”。窗口只显示这款产品的实际批号和水平。
2. 在窗口内新增或编辑批次，按实际采购资料登记各水平的批号和效期。保存或取消后，返回当前产品的批次列表。
3. 在同一窗口中停用或恢复批次。一次多水平检测的各水平可来自不同的已确认批号，录入时逐一核对；验证和使用安排在关联项目的批次管理中核对。

### 在关联项目弹窗中维护适用检验项目

在“质控品名录”单选产品，点击 **查看／管理关联项目**。

1. 在弹窗中点击“选择检验项目”，进入选择视图。
2. 在“查找检验项目”输入部分名称、编号或已登记的别名。勾选列表行首选择框，可同时选多项。
3. 更换搜索词继续查找，之前的勾选会保留。展开“已选检验项目”核对全部选择；可逐项移除，也可点击“清空已选”。
4. 点击“确认选择”，将选择带回关联项目管理；点击“取消”也返回关联项目管理，并保留进入选择视图前的选择。
5. 回到关联项目管理后核对所选列表，填写“核对人”和“参考资料”，例如产品说明书名称及页码。
6. 点击“保存适用项目”，看到保存成功提示后完成。**“确认选择”只带回尚未保存的选择，最后点击“保存适用项目”才保存。**

要放弃本次修改，点击“取消修改”，再按提示“放弃修改”。保存后，配置项目时可通过“整组添加检验项目 → 质控品适用检验项目”带入，继续逐项核对方法、单位和质量要求。

### 浓度、水平与方法怎样填写

- 产品编号、产品名称、浓度、浓度编号保留原文。浓度与浓度编号任一项有明确有效内容即可，不要求两项同时填写。
- 阴性、阳性、分型、基因型及基因位点按原文保留，不强制数值化；阴性不需要补造浓度。
- “/”仅为占位；有一项填写完整时，另一项可留空或保留“/”。两项均无有效内容才需核对。
- 同一检测目标的多个水平是正常材料结构。各检验项目分别设置质控方法，多水平产品不会自动选择多水平法或替换已经选定的方法。
- 目录浓度不作为检验项目的均值或标准差。产品资料可以保留文字，检测结果仍按检验项目配置的数值类型填写。

## 建立整组项目并确认批次

1. 新建项目，选择仪器；点击“从产品名录选择”，核对厂商、产品编号、名称、浓度和浓度编号，再点击“使用此目录产品”。继续核对必要默认资料并保存项目。
2. 用“整组添加检验项目”从已有项目或“质控品适用检验项目”带入，也可自行选择检验项目；先预览，再保存。
3. 逐项配置质控方法、检测方法学、单位、试剂、真实检测值/Ct/log输入类型、水平数及质量要求。同一项目的不同检验项目可以不同；默认带入不替代逐项核对。
4. 再次选中已有检验项目时保留其原有设置。应用共同默认值前先确认作用范围，避免覆盖不应修改的项目。
5. 在批次管理中登记本次实际批次，核对全部水平材料、均值和标准差来源、质量要求、验证结果及使用期间，再确认使用。
6. 人工或厂家参数须确认全部水平、参数依据、确认人和生效时间；未来参数在到达生效时间后使用。

项目配置可导入、导出。导入先看文件预览及合并/替换范围，替换须再次确认；复制、导入或换批后仍需完成本机质量要求核对。产品目录、项目配置文件和结果文件用途不同，配置导入不等于已经录入检测结果。

## 质量要求：先核对适用条件

在“资料与批次 → 质量目标”查找现行标准，核对来源、版本、条款、检验项目、单位及适用范围。目录区分项目要求与通用过程要求；废止、尚未生效版本及参考区间不作为日常采用目录。

- 补齐检测技术、结果性质、结果尺度、用途及标本/基质。明确适用的数值、定性及信号精密度要求必须采用，不能用较宽自定值替代；条件不明确时先保存待确认资料。
- “对照与质控要求”按本实验室实际情况维护。默认带入的条款供参考，可删减参考来源或全部不选；实际要求文本可编辑、删减或留空，核对后随质量要求保存。
- 参考来源保留原条款，选择来源不等于完整采用原文。报告分别列出“本实验室实际对照与质控要求”和“对照与质控要求参考来源”；实际要求留空时，不会用参考原文补填。
- 数值要求保留现有 WS/T 403—2024、WS/T 406—2024 的适用内容。具体分子条目与方法/对照依据的关联，不代表每个检测项目都有通用国家 CV。
- HCV RNA、HIV-1 RNA 专项按确切检测对象和尺度核对。现有 HIV-1 RNA 定量要求须使用 Log10 结果，项目输入类型和尺度均需对应；软件不在录入时自动转换原始结果，不能泛用到 HIV-1 DNA、HIV-2 RNA 或抗原抗体项目。
- Ct、log、浓度、S/CO、纯阳性/阴性分别核对，不互套 CV。对照与质控要求的文字设置及定性条款不自动评价，当前数值工作台不接收纯阳性/阴性检测结果。
- “目录没有”不等于“无适用标准”。按实际项目查找官方来源并保存复核记录；找到未收录标准时补充全文、版本、条款和核查记录。
- 可补充更严的同尺度 CV，保留标准基准和补充依据。自动评价限于已有适用 CV；SD、偏倚、总误差及文字条款不自动评价。采用标准或 CV 满足要求本身不代表检测在控。
- 已确认批次保留原采用记录；新批次、复制和导入后重新确认现行且适用的要求。

目录未收录某项目时，仍需查阅相关标准并保存适用性核对记录。

## 整组录入：填写或粘贴后两步保存

在所选项目内打开“整组录入”，选择本次实际批号或完整材料组合，点击“展开本组录入”。先核对项目、仪器、检验项目、单位、输入类型、全部水平和试剂批号。

1. 填写检测时间和检测人，按表格输入结果。Enter、Tab只结束编辑并移动输入格，不直接保存。
2. 采用多水平法的一次检测须填写完整的全部水平。可以选择本次需要录入的检验项目，但不能只保存同一次多水平检测中的一部分水平。
3. 粘贴时按页面项目和水平顺序提供检测值一列，或检测值、备注两列。先“预览粘贴内容”，检查位置与空白，再“确认带入本组”。空白不会被当作零。
4. 粘贴数量按当前页面的实际水平行数及顺序核对，多水平一次检测必须完整填写。
5. 使用结果文件时，先下载“本组结果模板”，填写后上传、预览，再“带入结果草稿”。文件带入也不直接保存检测记录。
6. 点击“核对并保存”，检查全部数据、实际试剂、材料和质量要求；无误后再点“确认保存整组”。任一项有错误，本次整组都不保存，输入仍保留；按具体错误修改并重新核对。
7. 保存成功后查看各项保存结果、各水平检测值和质控图。重复确认不新增记录；下次检测点击“再次检测，开始新一组”。

资料变化后按“保留输入并重新核对资料”刷新，不用重新抄写全部结果。切换页面或取消核对后，可返回继续填写草稿；不再需要时使用“放弃本组草稿”或“清空本组输入”。关闭应用或刷新浏览器前，先保存需要保留的结果。

## 今日总览与单项判读

“今日质控总览”按日期、仪器、项目、质控品和方法查询。选择项目可查看完整水平、实际批号及异常来源，也可在选定项目后进入整组录入。最新一次在控不会消除当日曾失控或跨日未完成的处理；尚未打开处理的正式失控也会保留提示。未建立执行计划时不计算漏做率。

以下规则适用于已经在检验项目中选择相应方法的情况，不由质控品包装或材料水平数自动决定方法：

- **单水平（LJ）**：按本批次数据建立参数，或使用已经确认的人工/厂家参数及其生效时间；查看 LJ 图与规则提示。参数建立期的疑似离群需人工复核，系统不自动剔除。
- **多水平法**：当前支持2或3个完整水平的联合判读；任一水平触发拒绝规则时，整次检测失控，其余水平仍作为明细展示。参数建立期的保留、禁用和恢复按整次检测联动，正式期建立记录只读。
- **即时法**：3个有效点后开始格拉布斯检验并显示SI提示；累计20个有效建立点后可人工确认转入LJ。20点不是20天，不自动转入；原即时法记录保留。

## 失控处理、复测和附件

1. 从今日总览、检测记录或月度回顾打开对应异常，登记处理记录。
2. 填写原因分类、原因分析、纠正措施、处理效果及依据、处理人；按实际情况登记患者影响范围、评估、措施和依据。
3. 关联同检测系统的后续实际复测，核对检测时间、完整水平、批号和参数；存在差异时说明原因。取消已保存的复测关联也需说明原因。
4. 选择附件、填写说明并“加入附件草稿”，保存处理记录后才随版本归档。历史版本引用的附件仍保留。
5. 先“保存处理草稿”，再“提交效果确认”，由人工核对后“确认完成”；需要补充时退回继续处理。
6. 可生成所选处理版本的独立PDF，查看旧版本与附件。已完成记录需修改时使用“新增处理修订”，原记录、原判读和旧PDF保留。

复测在控不会自动完成处理，也不会把原失控结果改成在控。请如实填写处理人和确认人，并按实验室制度核对签字。填写姓名不等于账号登录或审核授权；患者结果须另按实验室流程审核放行。

## 批量月报和原报告历史

1. 打开“批量月报”，选择月份、仪器、项目和方法，点击“核对待生成清单”。检查可生成项及不生成原因；同月多个实际批次分别列出。
2. 选择所需报告，点击“生成所选月报并分别归档”。每份独立保存，一份失败不影响其他成功项；只继续未完成或重试所选项。
3. 下载成功报告及完整清单，或下载某份原报告、打开其报告历史。清单保留未生成、待继续和排除原因。
4. 单项工作台仍可生成相应批次月报。“按当前数据重新生成”会另存新报告，不能覆盖旧PDF；下载原报告直接读取原归档。
5. 资料在生成期间变化时，重新核对再生成。月度回顾沿用该份报告归档时的检测与处理资料，之后的处理修订不会悄悄改写旧报告。

月报仅纳入所选常规正式期，Z-score以完整检测计次。即时法不直接提供月报；转入LJ后按对应LJ批次生成。临时质控不并入当前月报。

CV按批次、参数版本和水平分别展示，只使用正式期在控结果；多水平整次失控时，该次其他正常水平也不纳入在控CV。未采用适用要求、数据或检测日数不足时明确不能评价，不显示为达标。月度回顾不是自动审核、签字或患者放行。

## 批号管理与使用范围

在批号管理中登记试剂/质控品批号、验证结果、使用状态和生效时间，按需要查看参数版本、各水平批号和使用记录。停止使用后保留历史。更正试剂默认使用安排会新增关联记录，不修改既往检测时保存的实际批号、检测值或原判读。

本说明适用于常规室内质控。临时质控、质控品新旧批比对和患者样本试剂比对须另按实验室流程开展，本软件暂不提供相应专用操作。已保存检测值不能通过修改批号设置来更正，当前也不提供历史检测值更正或补录；发现误录时请保留原始记录并按实验室流程登记。

## 完整备份、恢复与保存位置

在“系统设置”创建和管理完整备份。请保留完整备份文件，其中包含检测资料、处理附件及原报告；不要只复制单个数据文件。移动资料、更换电脑或恢复前先备份。

恢复会替换当前数据，先核对备份文件与时间，再按页面确认。更改保存位置使用页面文件夹选择，完成后按提示重启。

双击“启动质控软件.command”打开当前软件。新增操作保存在系统设置中的当前保存位置，关闭后重新打开仍可继续查看和操作。
