# 质控软件使用说明

更新日期：2026年11月6日。首次使用从第一项开始；日常工作选择需要的操作。软件**帮助 → 使用说明**按这些章节展开，完整步骤见[操作说明](OPERATION_GUIDE.md)。

桌面版安装包从网页版的**帮助 → 软件下载**获取；当前为开发版，安装提示与文件校验值也在该页面。桌面软件不显示软件下载入口；两端顶部各自标明版本和构建号。

首次方法选择按本实验室的质控方案进行：单水平按一个浓度水平的均值和 SD 建立 L-J 图；多水平按各自均值和 SD 评价不同浓度水平，再综合判读。方法含义与 Westgard 参考来源见操作说明的**首次使用**。

首次引导先选**单水平（L-J）**或**多水平法**，再按**实验室信息 → 仪器试剂管理 → 新建项目**操作；方法可在建项时修改，教程可从**帮助 → 新手教程**查看。资料也可从**单位资料准备**批量导入Excel。Ct项目可单独设置提醒线；日常结果在**今日质控总览**查看。即时法转入L-J后可继续同项目整组录入，核对后再保存。参数切换、导出及期间报告按对应章节操作。
