## 1. 目标与确认需求

校准、试剂批号变更、仪器搬迁或维护后，可以独立登记临时质控并独立判读。没有当日常规结果也能录入；临时值保留在数据表，不纳入常规 L-J 统计，图上显示与否可选择。

临时质控是一类业务记录，不等于现有即时法。原因、结果与判读必须结构化保存，不能只记为备注。

## 2. 依赖与职责

- 复用既有仪器、项目、具体批次、水平、参数及结果服务；任务 2A 提供新增资料关联。
- 复用 [任务 1](task_01_out_of_control_reports.md) 的失控处理和复测关联。[任务 2](task_02_daily_workbench.md) 提供日常入口衔接；本任务负责临时录入、判读与统计隔离的完整验收。
- 当前数据表和既有报告中的临时记录归属在本任务落实，后续 [任务 3C](task_03_comparisons_and_monthly_reports.md#4-3c批量月报与汇总) 复用相同口径做批量生成。
- 更正、补录临时值时的重算由任务 5 接入，不因此在本任务先开发账号和历史维护。

## 3. 交付范围

1. 独立“临时质控”入口；常规录入处的“变动：是/否”可进入同一流程，不强迫先造一条常规结果。
2. 保存检测时间、仪器、检测项、具体质控批次、水平、实际试剂批号、变动原因和结果，关联实际使用参数及判读。哪些上下文字段为必填按现有适用规则核对，不用当前默认值猜填历史。
3. 调用适用的现有算法产生独立结果。判读上下文明确，不修改质控公式，也不把常规序列是否参与临时跨点规则的问题默认为已解决。
4. 数据表可查看临时结果、原因和结论；显示开关只影响图面，不能改变有效点数、均值、SD、CV或其他常规统计的纳入范围。
5. 临时失控关联原因分析、措施与复测；新增复测记录，保留原结果。当天多次临时检测分别保留。
6. 导入导出能够识别临时类型和原因，不能导出后再导入时变成普通质控值；备份恢复保留类型、判读及事件关系。

## 4. 必须先明确的计算分支

已确定：独立录入、独立判读、不纳入常规 L-J 统计。尚未确定：临时判读是否使用临时序列的连续规则、是否引用常规历史窗口，以及月报总失控次数是否包含临时结果。

实施前核对并确定上述分支，不擅自改算法或分母；其余记录结构、入口与资料关联可以先做不依赖该答案的设计准备。月报如何分列或合并属于待确认方案，不能因为暂未确定就丢弃临时失败结果。

## 5. 验收条件

- 无常规记录时能独立录入；同日多次临时记录不覆盖、不重复，保存后可查看独立结论。
- 使用已确认参数的案例验证数值和判读一致；缺少适用参数时给出明确状态，不伪造在控结论。
- 对照加入临时值前后的常规统计和判读序列，按最终确认的隔离规则验证；常规 L-J 统计不混入临时值。
- 切换图上显示不改变统计归属；数据表、导出及报告对类型和结果的表达一致。
- 临时失控能进入任务 1，复测与原因关联正确；多水平采用既有完整 run 和参数来源规则。
- 导入导出、备份恢复和失败重试后，临时类型、批号、时间、判读和关联不丢失。
