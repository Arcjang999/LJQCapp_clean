## 1. 本版可以试什么

1. 首页查看、筛选、新建项目。勾选行首选择框进入项目工作台；返回后保留原选择。项目默认质控方式和方法学只带入以后新增的检验项目，支持逐项覆盖及混合配置。
2. 项目、检验项目、质控产品和实际材料的新增/编辑使用弹窗。保存失败保留输入；未保存修改取消时提供继续编辑/放弃。项目、材料和批次停用/恢复使用确认弹窗；检验项目移除为可追溯停用，不删除历史结果。
3. 质控品资料中把浓度水平、浓度编号、实际批号和效期一并登记。浓度编号为文本，保留前导零；首次配置即可选择不同实际批号组成多水平组合。
4. 项目工作台选择检验项目和批次，直接进入相应工作台的“当前批次”。即时法转入 LJ 后，项目入口定位到转换后的 LJ 批次。旧方法入口折叠保留。
5. 新建/编辑配置必须确认质量目标来源。有标准候选时逐条采用或说明不适用依据；没有适用条目时记录实验室要求、版本、确认人及依据。Ct/log 不套用浓度尺度 CV 要求；项目确认后，新批还需核对实际材料的适用性。
6. 批次复制和换批先形成待核对草稿，重新确认来源及各水平参数后才能启用。配置导出增加只读来源核对页；导入不能把这些查阅内容冒充已确认记录。

质量标准来源沿用已有目录和准确分类。WS/T 403/406 是卫生行业标准；本版的“必须核对”是软件配置规则，不将其宣称为强制国家标准。不仅凭检验项目名字或工作分组判定适用性。
