# CV 建立与显示口径（2026-09-11）

用户反馈：批次管理缺少 CV%，且建立设置与后续工作台对不上。本次修复不涉及质量目标库或自动选择质控规则。

## 依据与取舍

- [Westgard：均值、SD 与 CV](https://www.westgard.com/lessons/basic-qc-practices/lesson14.html)：CV% = SD / mean × 100；质控界限用均值 ± 若干 SD。CV 要求不能直接代替 SD，也不能仅凭 CV 达标断定某次结果在控。
- [Westgard：质量要求与 Sigma](https://www.westgard.com/lessons/qwestgard-rulesq/lesson74.html)：实际不精密度 CV 与允许总误差 TEa 属于不同量。保留实验室按检验项目填写的 CV 上限及依据，不自动设置通用 5% 或把 TEa 写入 CV 要求。
- [NIST：CV 的适用尺度](https://www.itl.nist.gov/div898/software/dataplot/refman2/auxillar/coefvari.htm)：CV 适合具有实际零点的比例尺度。Ct / log 参数旁提示按当前尺度计算，不能直接套用浓度的 CV 上限；不做隐式反变换。均值非正、接近零（≤ 1e-12）或非有限数值时不显示可用 CV，不再让负 CV 被判断为满足正上限。
- Westgard 建议通过跨日测量估计稳定均值与 SD；本次不改已有 5–20 点的产品设置，不把点数门槛等同于充分性能验证。

## 已实现

1. 添加检验项目时可填 CV 要求上限和依据。新建批次自动带入，可逐项目调整；留空保持未设置，不填假默认值。
2. 尚未启用且从未绑定工作台的草稿可保存 CV 要求和依据，增加配置修订快照。复制批次继承要求。已经启用或绑定过的批次保持原值，服务层拒绝修改，避免历史解释漂移。
3. 均值、SD 对应的靶值 CV% 自动计算，不增加一个可以与 SD 矛盾的独立 CV 靶值输入。建靶来源显示“建靶后计算”；复制参数标为待确认参考。
4. 存在当前生效参数版本时，批次管理直接显示该版本的各水平靶均值、SD、CV%；调整入口指向“批号使用与追溯 → 靶值版本”。参数确认页默认填入当前生效版本，输入均值和 SD 后立即刷新 CV 和上限比较。
5. LJ 当前参数统计使用当前生效版本，避免最后一条旧版本检测覆盖当前参数展示；检测明细及保存判读仍使用当时的版本。当前控制参数不再标为累计建靶 CV。Z-score 正式参数增加 CV 要求比较，并纠正已确认版本的阶段文字。
6. 统一配置预览、LJ、Z-score、即时法、月报的 CV 计算。批次 XLSX 水平表及参数历史表增加“靶值 CV%”。不回写原始检测数值或已保存判读，不新增 schema。
