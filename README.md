# 实验室室内质控管理工具

## 项目简介

这是一个基于 Python、Streamlit、SQLite、pandas 和 matplotlib 的本地室内质控工具，当前版本包含以下页面与模块：

- `Main` 欢迎页：用于说明产品定位、方法入口、快速开始和使用教程
- `LJ` 模块：单水平 LJ 曲线质控主流程
- `Z-score` 模块：双水平 / 三水平多水平 IQC 主流程
- `Instant` 页面：预留页，当前仅保留模块定位说明，未接入正式业务逻辑

当前版本适合作为内部试用、演示和小范围部署的基线版本。

- 单水平图 / 合并图

### Instant

- 未接入正式业务逻辑

## 更新记录

### 2026-04-05 更新：数据的导入导出

#### 本轮改动

- LJ：当前批次已支持按阶段导出建靶期 / 正式期数据，格式可选 Excel / CSV；已支持当前 LJ 图 PNG 导出，以及仅基于正式数据的月度质控图 PNG 导出
- LJ：已提供建靶期 / 正式期 CSV 模板下载、CSV 审查与确认导入；审查结果会返回总行数、可导入行数、错误行数、警告行数，并展示逐行问题
- Z-score：当前批次已支持按阶段导出建靶期 / 正式期 run 宽表，格式可选 Excel / CSV；已支持当前图 PNG 导出，以及正式期月度图 PNG 导出
- Z-score：已提供建靶期 / 正式期 CSV 模板下载、CSV 审查与确认导入；模板会按当前批次 2 水平 / 3 水平自动生成，审查结果同样返回摘要与逐行问题
- 导入审查：阻断错误会禁止确认导入；非阻断项保留为提醒，覆盖模板不匹配、缺少必填列、模板外列、检测时间重复、备注为空等常见情况

#### 当前限制 / 已知边界

- 导入入口当前仅支持标准 CSV 模板，不支持 Excel 导入，也不支持跨批次批量导入
- LJ 月度质控图与 Z-score 月度图当前都只导正式期数据，日期范围最长 30 天
- Z-score 建靶期导入仅在当前批次未完成建靶时开放；正式期导入需建靶完成后再执行，建靶期文件不能跨阶段直接导入到正式期
- 导入为追加写入当前批次；确认导入后会按现有业务口径刷新统计、判定、图表与最新结果分析

## 运行方式

### 安装依赖

```powershell
python -m pip install -r requirements.txt
```

### 启动应用

直接运行 Streamlit 入口：

```powershell
python -m streamlit run app.py --server.headless true --server.port 8506
```

也可以使用启动脚本：

- `run_app.py`
- `run_app.bat`

### 入口文件

- 主页面入口：`app.py`
- 打包后启动入口：`run_app.py`

### 数据库初始化

- 应用启动时会自动执行数据库初始化，无需手工建表
- 数据库默认持久化位置：
  - Windows：`%LOCALAPPDATA%\LJQCApp\qc_lj_app.db`
  - 无 `LOCALAPPDATA` 时：`~/.ljqcapp/qc_lj_app.db`
- 如需清空试用数据，可运行：

```powershell
python reset_db.py
```

也可以使用：

- `reset_db.bat`

## 使用说明摘要

### LJ

1. 新建项目
2. 新建批次并确认建靶所需次数
3. 录入检测结果
4. 建靶完成后自动进入正式质控
5. 查看图表、规则汇总和最新结果分析
6. 如需修正历史数据，使用记录维护入口

### Z-score

1. 新建项目，并确定双水平或三水平
2. 新建批次并填写各水平说明
3. 录入多水平检测记录
4. 全部水平达到建靶条件后进入正式质控
5. 查看单水平图、合并图和最新结果分析
6. 如需修正正式期记录，使用记录维护入口，系统会自动整批次重算

### 测试版更新：批次级 CV 要求（%）

#### 更新内容

- LJ 与 Z-score 的新建批次均支持可选填写“CV 要求（%）”
- 当前已有的编辑批次入口支持回显和修改“CV 要求（%）”
- 该值保存为批次属性，工作区只读取已保存值做提醒，不提供第二套临时输入入口
- LJ：建靶过程中一旦已有足够数据可计算 SD/CV，就开始显示“当前累计 CV%”与“批次要求”的对照提醒
- Z-score：建靶过程中按各水平分别显示 provisional CV% 与“批次要求”的对照提醒
- 提醒只作提示，不阻断保存，不改变现有判读逻辑与建靶/正式期切换逻辑

#### 使用方法

1. 在“项目与批次管理”中先选择项目，再新建批次
2. 新建批次时可选填写“CV 要求（%）”；留空则表示该批次不启用此提醒
3. 如需调整，可在当前已有的编辑批次入口修改并保存
4. 进入工作区后，系统只读取该批次已保存的 CV 要求并显示提醒，不需要也不能在工作区再次录入
5. 当批次未设置 CV 要求时，系统保持兼容，不报错，也不强制显示空提示

#### 手工测试步骤

1. LJ：新建批次时填写 CV 要求，例如 `5.00`，保存后进入当前批次页
2. LJ：连续录入至少 2 条建靶结果，确认开始显示“当前累计建靶 CV% / 批次要求 / 是否满足要求”
3. LJ：新建批次时不填写 CV 要求，进入工作区确认不报错、无空提示
4. LJ：通过编辑批次修改 CV 要求后再次进入工作区，确认提醒读取的是修改后的已保存值
5. Z-score：新建批次时填写 CV 要求，录入多水平建靶 run，确认各 level 分别显示 provisional CV% 对照提醒
6. Z-score：旧批次或未设置 CV 要求的批次进入工作区，确认不报错
7. 回归一遍现有 LJ 主流程
8. 回归一遍现有实际生效的 Z-score 主流程
