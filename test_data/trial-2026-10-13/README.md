# 2026年10月13日试用测试数据

这份备份保存了当前软件里的项目、产品、批号、检测记录、处理记录、报告和附件。使用同一 branch 的软件打开即可查看。

## 怎么使用

1. 下载本目录的 **trial-data.zip**，保持ZIP文件原样。
2. 打开软件，点击 **系统设置**，找到 **从备份恢复数据**。
3. 点击 **选择备份文件**，选择 **trial-data.zip**。
4. 勾选恢复确认，点击 **确认恢复数据**。
5. 重新打开软件，在首页选择项目查看检测记录、质控图和报告。

**恢复会替换软件当前数据。恢复前软件会自动备份当前数据，请保留该备份。**
